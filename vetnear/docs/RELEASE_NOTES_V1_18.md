# VetNear v1.18 — clinical premium 3D system

## Що змінилося

- Створено оригінальну code-native SVG-систему м’яких 3D-іконок VetNear: клініка, аптека, перетримка, грумінг, невідкладна допомога, укриття, геолокація, дзвінок, маршрут, перевірка, фільтри та профіль тварини.
- На `/nearby` результати підняті вище: список/карта доступні у верхній панелі, радіус лишився компактним, а розширені параметри заховані під одним контролом «Фільтри».
- Неактивний сценарій укриття згорнуто до тихого статусного рядка. Під час підтвердженої тривоги зберігаються повний блок безпеки, швидкий маршрут і можливість одним натисканням вимкнути автоматичні підказки.
- Картки закладів отримали чіткіші головні дії «Зателефонувати» та «Маршрут», нові 3D-іконки й стриманішу глибину.
- Сторінка закладу та мобільна sticky-панель використовують ту саму систему дій.
- Домашня сторінка, сценарний rail, категорії та trust-картки приведені до одного матеріалу й освітлення.
- Рух обмежено коротким входом, м’яким підйомом і легким нахилом на fine-pointer; `prefers-reduced-motion` вимикає ці ефекти.

## Безпека та чесність даних

- Логіку телефонного підтвердження термінових/24/7 заяв не послаблено.
- Маршрут до укриття лишається активним тільки під час свіжої підтвердженої тривоги.
- При застарілому або недоступному статусі кнопка укриття залишається вимкненою.
- UkraineAlarm token не зберігається у клієнтському коді чи архіві.
