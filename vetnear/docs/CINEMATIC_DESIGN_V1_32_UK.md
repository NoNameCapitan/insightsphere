# VetNear 1.32 — кінематографічний дизайн

Візуальна тема: близькість людини й тварини, тепле світло та просторове відчуття міста. Темний бірюзовий фон, молочний текст, стримані бурштинові акценти; основні робочі екрани залишаються світлими. Типографіка Manrope локальна, без зовнішнього запиту до сервісу шрифтів.

## Головні зміни

|---|---|---|
| Об’ємний символ у світлому колі | Кінематографічна сцена із собакою, котом і кроликом, тепле бічне світло | Пов’язати візуальний характер з реальною темою турботи |

## Рух

- Головне зображення: один плавний наїзд камери; на настільному пристрої — невелике зміщення глибини за вказівником. Немає фонового відео, аудіо чи нескінченного циклу.
- Карту побудовано на наявних геометріях районів OpenStreetMap. Просторові шари, світло, активний район і перспектива пояснюють вибір.
- Елементи керування реагують швидко. Пошукова форма доступна до завантаження JavaScript і до завершення декоративної анімації.
- Системний `prefers-reduced-motion` дає статичний варіант. На карті є окреме вимкнення руху; на desktop головного зображення також. На mobile головне зображення має лише коротку початкову появу без pointer-руху.
- Автоматичне проявлення всіх секцій вимкнено. Залишений механізм працює тільки для явно позначених `data-reveal` регіонів.
- Для районів є альтернативний HTML-список кнопок, видимий фокус і статус вибору. Декоративні шари карти приховані від екранного диктора.

## Зображення

`public/visuals/cinematic-companions.webp` — створена для цієї ітерації ілюстративна AI-фотосцена, оптимізована у WebP. Вона не є фотографією конкретної клініки, її клієнтів або події. Вихідний згенерований PNG збережений окремо в робочому середовищі; для сайту використовується оптимізований актив.

## Межі перевірки

Зображення перевіряються на desktop і mobile, а взаємодії — проти production-збірки. Перевірки реальних Safari/iOS/Android-пристроїв, повний аудит екранним диктором і вимірювання польових Core Web Vitals залишаються умовами публічного запуску. Локальна перевірка не є заявою про повне WCAG-сертифікування.
