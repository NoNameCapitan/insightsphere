manually-curated list of **real** Kyiv pet businesses: **30 verified places + 34
web-researched candidates (`needs_review`)** = 64 total.

### Review workflow (to flip a candidate to verified)
1. Open `data/imports/manual-candidates-review.csv` — one row per candidate with
   phone/address/source and empty check columns.
2. Call or check the official site: confirm phone, address, hours.
3. In `scripts/build-verified-places.mjs`, move the confirmed row from
   `RAW_CANDIDATES` to `RAW` (verified block), or edit its status fields.
4. Re-run `node scripts/build-verified-places.mjs && node scripts/gen-products.mjs`
   and `npm run verify`.

## What is real
- **Names, addresses, phones, websites** are compiled from official sites and public
  directories: aldenvet.ua, avet.kiev.ua, masterzoo.ua, dogcity.ua, puggi.com.ua,
  and public listings (locator.ua, 2GIS, kyiv directories).
- Categories: veterinary_clinic (15), pet_store (10, MasterZoo branches),
  vet_pharmacy (2, Alden-Vet pharmacy desks), grooming (2), pet_boarding (1).

## Verification level (be honest in the demo)
- `dataSource: "manual_verified"`, `verificationStatus: "verified"`, `verified: true`.
- `verifiedBy: "VetNear team (public listings + official sites)"` — this means the entry
  was compiled and cross-checked against **public web sources**, NOT phone-confirmed.
- `lastVerifiedAt: 2026-06-29`.
- **Coordinates are approximate** (street/district level), good enough to land the map
  pin in the correct neighbourhood. Re-geocode against the official address before any
  real launch.

## Emergency safety (intentional)
- `emergencyAvailable` and `isOpen24_7` are **false for every place**, and no place uses
  the `emergency_vet` category — even though some clinics (Alden-Vet, A-Vet) advertise
  24/7 service. We do **not** mark emergency availability without a phone confirmation.
- Result: public emergency results are intentionally **empty** (the app shows its
  emergency empty-state). This is the honest state for the demo.

## Before a public launch
1. Phone-confirm each clinic's hours and emergency/24-7 capability; only then set
   `emergencyAvailable` / `isOpen24_7` and (where appropriate) the `emergency_vet` category.
2. Re-geocode addresses to exact coordinates.
3. Confirm phones/working hours are current; add missing websites/socials.
4. Consider adding pet_friendly_place, shelter and animal_volunteer_help entries
   (left out here because their public phone numbers were not confirmed).

## Regenerating

```bash
node scripts/build-verified-places.mjs   # writes src/lib/data/places.ts
node scripts/gen-products.mjs            # relinks demo inventory to the new store ids
```

## MVP data model (what is real vs. demo)

- **Public places:** 30 manually curated Kyiv businesses (`manual_verified`, verified
  against public sources, not phone-confirmed). Coordinates approximate.
- **Product inventory:** synthetic/demo only (regenerated by `scripts/gen-products.mjs`).
- **Emergency / 24-7:** disabled until phone-confirmed (`emergencyAvailable`/`isOpen24_7`
  are `false`; future-ready fields `phoneConfirmedAt`/`phoneConfirmedBy`/`emergencyNotes`/
  `supportedEmergencyAnimals` exist for when a call is made).
- **Partner submissions:** moderated via `/admin/moderation` and never auto-published;
  partners cannot self-declare emergency. Google Places candidates are external,
  review-only leads.
- **User state** (pets, submissions, reports, review decisions): localStorage only,
  typed for a future Supabase/Postgres migration.
- **Social impact:** the 10% commitment applies to paid partner/subscription/sponsor
  revenue, not automatically to investment/grant capital (see README).
