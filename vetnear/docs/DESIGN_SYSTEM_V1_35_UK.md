# VetNear 1.35–1.36 — дизайн-система: теми, кольори, світло, рух

Основа для наступних ітерацій. Коротко: **колір — лише через токени, темна тема — через атрибут `data-theme`, рух — лише прогресивне покращення.**

## 1. Як працює тема

| Шар | Файл | Роль |
| --- | --- | --- |
| Логіка | `src/lib/theme/theme.ts` | `system / light / dark`, збереження у `localStorage` (`vetnear:theme`), подія `vetnear:theme-changed`, оновлення `meta[name=theme-color]`, bootstrap-скрипт |
| Перший кадр | `src/app/layout.tsx` | Inline-скрипт у `<head>` ставить `<html data-theme>` до першого малювання: тема не блимає. CSP вже дозволяє inline-скрипти |
| Перемикач | `src/components/ThemeToggle.tsx` | Цикл «як у системі → світла → темна». Стежить за ОС, поки обрано «як у системі». Під час друку тимчасово вмикає світлу тему |
| Токени | `src/app/theme.css` | Світлі й темні значення всіх кольорів. Ручні виправлення для темної теми |
| Похідні правила | `src/app/theme-dark.generated.css` + блоки `@generated` у `*.module.css` | Автоматично виведені з світлих стилів (див. §3) |

Компоненти **ніколи** не перевіряють тему в JS. Будь-яка відмінність задається в CSS.

## 2. Палітра темної теми «Вечірній дім» (з 1.36)

Вітальня ввечері після того, як увімкнули лампу. Темні поверхні — теплий умбровий, а не холодний ліс. Текст кремовий, дії шавлієві, акцент — м'який бурштин лампи, корал лише для термінового. Нічого чисто чорного, нічого бірюзового: навіть найтемніший тон має трохи коричневого. Глибока сосна в героях і фічер-картках стає оливково-сосновою: та сама глибина, тепліше.

| Роль | Світла | Темна (1.36) | Tailwind / змінна |
| --- | --- | --- | --- |
| Полотно | `251 248 243` | `20 19 15` | `bg-canvas`, `--care-paper` |
| Поверхня | `251 253 252` | `29 27 22` | `bg-surface`, `--care-surface` |
| Лінія | `#d8ded0` | `#38342b` | `--theme-line`, `--care-line` |
| Текст | `20 43 40` | `241 234 221` | `text-ink`, `--care-ink` |
| Другорядний текст | ink 72 % | ink 66 % / `#b8ad99` | `text-ink/40…/60`, `--care-muted` |
| Дія (заливка) | `6 117 106` | `52 118 90` | `bg-brand`, білий текст |
| Посилання | `#245742` | `#b5dcbf` | `--theme-link` |
| Акцент лампи | `#b0813e` | `#e8b77c` | `--theme-gold`, `--c-amber` |
| Фокус | `#386e4b` | `#e8b77c` | `--theme-focus` (тепле світло) |
| Терміново | `207 68 54` | `194 65 47` | `bg-emergency`, текст `--theme-danger-text` |

Тіні в обох темах відкидає тепла лампа: вони коричнюваті (`rgb(74 48 22 / .26)`), не синьо-чорні. Виділення тексту — бурштинове.

Для Tailwind кольори — це канали (`--c-brand: 6 117 106`). Тому модифікатори прозорості (`bg-brand/10`) працюють в обох темах. Шкала `brand-50…300` у темній темі — це темні відтінки під заливки, а `brand-700…900` — світлий текст. Клас `text-brand-700` читається на будь-якому полотні.

Контраст ключових пар (AA ≥ 4,5:1) перевіряє тест `src/lib/__tests__/themeV135.test.ts`. Якщо ви змінюєте токен, тест покаже пару, що зламалася.

## 3. Темна тема для старих стилів: генератор

Багато стилів 1.2x–1.34 мають жорстко задані світлі кольори. Замість ручної копії кожного правила скрипт `scripts/gen-dark-theme.mjs` читає світлі стилі й створює темні відповідники за роллю кольору:

- **текст** (`color`, `outline`, `caret`…): темне чорнило стає світлим того ж відтінку; світлий текст лишається без змін;
- **заливка** (`background*`): світлі поверхні стають нічними. Темні заливки (кнопки, герой), насичені акценти та світіння (градієнти до `transparent`) не змінюються;
- **лінія** (`border*`): світлі розділювачі стають темними;
- правило з декларацією `--dark-keep: 1` генератор пропускає. Це для шарів, що завжди лежать на темній сцені героя: пил у світлі, тонкі роздільники з прозорими краями;
- кастомні властивості з назвою на `-ink / -muted / -line / -bg / -surface` обробляються так само;
- правило, що зберігає світлу заливку (золота кнопка), зберігає й темний текст. Градієнтний текст (`background-clip: text`), `body`, `html` і `@media print` не чіпаються.

```bash
npm run theme:dark    # перегенерувати після зміни світлих стилів
npm run theme:check   # входить у npm run verify; падає, якщо згенероване застаріло
```

Специфічність: згенеровані селектори мають префікс `:where(html[data-theme="dark"])`, який нічого не додає. Тому кожне перевизначення має рівно ту саму специфічність, що й світле правило, і перемагає лише порядком (блок у кінці модуля; глобальний файл — після світлих стилів). Пріоритет станів однаковий в обох темах: натиснута кнопка завжди сильніша за базову. Будь-яке ручне правило `html[data-theme="dark"] …` (у модулі чи в `theme.css`) завжди перемагає згенероване.

## 4. Як стилізувати нові компоненти

1. **Найкраще:** використовуйте токени (`text-ink`, `bg-surface`, `var(--theme-link)`). Тоді темна тема працює без додаткового коду.
2. Потрібен інший колір у темній темі — у CSS-модулі:
   ```css
   :global(html[data-theme="dark"]) .card { background: var(--theme-surface); }
   ```
   У глобальному CSS — `html[data-theme="dark"] .card { … }`.
3. Не використовуйте `@media (prefers-color-scheme: dark)` напряму: користувач може обрати тему, відмінну від системної.
4. Перевірка контрасту в браузері: протокол у `docs/qa/v1.35/README.md`.

## 5. Світло, рух і 3D (герой, з 1.36)

Сцена — вечірня кімната з лампою поза кадром угорі праворуч. Шари `CinematicCompanions` + `HomeHero.module.css`, знизу вгору:

| Шар | Що робить |
| --- | --- |
| `sceneImage` | Грейд: м'якший контраст (`contrast .92`), підняті тіні, легке тепло (`sepia .07`; увечері `.14`). Шерсть м'яка, не «хрустка» |
| `sceneWrap` | Світло, що *обіймає* тварин: тепле еліптичне `soft-light` навколо них і ледь помітна бурштинова вуаль на всьому кадрі |
| `sceneFill` | Відбите від килима тепле заповнення знизу: тіньовий бік шерсті лишається теплим і відкритим |
| `sceneLamp` | Ключове світло лампи: велике, м'яке, без променів. Увечері сильніше й тепліше |
| `sceneLight` | Ледь помітне тепло за точною мишею |
| `sceneMotes` | Пил у світлі лампи: 8 крихітних (2–4 px) порошинок, кожна на власному годиннику 26–40 с. Яскравіші лише в теплій зоні |
| `sceneShade` | Тінь кімнати навколо тексту з колом `--stage` і краплею бурштину — ніколи не чорна |
| `sceneGrain` | Зерно фотографії (7 %), не кіноплівки |

**Відкриття — вдих, а не ефектна поява.** Кімната трохи притемнена (`brightness .72`), камера на 3,5 % ближче. За 3,2 с око «звикає». Лампа розгоряється за 2,8 с, відбите світло — за 3,4 с. Рядки заголовка приходять на 0,45 em знизу за 1,5 с, без повороту й розмиття. «домом.» один раз ловить світло лампи: повільний теплий відблиск за 3,6 с осідає в м'яке сяйво. Летербоксу, різкого наїзду й спалаху більше немає.

Правила для нових ефектів:
- анімуйте лише `transform` / `opacity`, без бібліотек і WebGL;
- жодного постійного пульсу чи мерехтіння лампи;
- нахил за мишею — до 2,6°, з інерцією 1,4 с;
- кожен ефект мусить мати статичний стан, коли рух вимкнено;
- терміновий маршрут і пошук ніколи не залежать від анімації.

## 6. Що далі (закладено, але не активовано)

- Семантичні `--theme-*` токени вже є. Нові компоненти мають використовувати їх, щоб поступово скоротити згенероване.
- Тема висококонтрастного режиму: це третє значення `data-theme` плюс один блок токенів у `theme.css`.
- Збереження вибору теми в акаунті: подія `vetnear:theme-changed` — точка підключення.

## 7. Мобільний герой і поверхні під ним (з 1.37)

- **Пошук до 700 px:** одне поле на рядок, мітка ліворуч, значення праворуч. Кожне поле — м'яка «вдавлена» плитка (`inset`-тінь) висотою ≥ 52 px; кнопка на всю ширину, 54 px. На десктопі поле під курсором або фокусом трохи вдавлюється; під формою — ледь помітне світло лампи.
- **Послуги до 700 px:** горизонтальна стрічка карток (148–168 px) зі snap. Третя картка визирає, щоб було видно, що стрічка гортається. Скролбар прихований, свайп і клавіатура працюють.
- **Фокус у пошуку** бурштиновий (`#b07a35` у світлій темі, `#e8b77c` у темній) — тепле світло, а не синій чи зелений контур.
- **Роздільники між секціями:** волосяні лінії, що згасають на краях (бурштин → м'ятний). Не рамки й не смуги.
- **Іконки** (place-card, owner-home) — маленькі підняті плитки: верхній відблиск і тепла тінь контакту.
- **Специфічність форм у темній темі:** глобальне правило для `input/select/textarea` має специфічність (0,1,1), тож компонент завжди може задати свій фон.


## 8. Преміальні поверхні (з 1.38)

- **Темні «кімнати».** Інтро партнерів, картка пілоту, партнерський блок на головній і смуга оновлень мають одну мову з героєм: соснова глибина, лампа вгорі праворуч (`rgb(255 190 120 / .2–.24)`), тепле відбите світло знизу. На такому тлі текст кремовий, акцент бурштиновий.
- **Золота дія.** Головна дія на темній кімнаті — золото (`#f7dfb0 → #ebc483`, текст `#1b3a2c`), а не бірюзова кнопка: це запрошення, а не відправка форми. На світлому тлі лишається `btn-brand`.
- **Освітлені картки.** Слонова кістка з теплом лампи в куті, рамка `#e6e0cf`, тінь `rgb(74 48 22 / .45)`. Іконки — підняті плитки з верхнім відблиском.
- **Ховери.** Лише за точного вказівника. Підйом 1–2 px і тепле сяйво; за `prefers-reduced-motion` колір і сяйво лишаються, руху немає.
- **Заголовки під героєм:** вага 620, трекінг від −0,03 до −0,034 em, висота рядка 1,12–1,18; друга частина заголовка приглушена або бурштинова.
- **Шар для мобільного й темної теми:** білі верхні відблиски (`inset 0 1px 0 #fff`) у темній темі замінюйте теплим краєм `rgb(255 226 186 / .06)` — генератор тіні не змінює.

## 9. Іконки категорій — один матеріал (з 1.39)

`ServiceIcon` — іконка категорії скрізь: картки закладів, плитки послуг, макет телефона, картки категорій, сторінка закладу.

- **Матеріал:** матовий об'єм слонової кістки з шавлієвим відтінком, освітлений теплим джерелом згори ліворуч (градієнт `--svc-hi → --svc-lo`).
  - контур — колір контексту (`currentColor`), 1,5 на сітці 32;
  - один характерний акцент (`--svc-accent`, корал `--svc-urgent` — лише для термінової допомоги);
  - тонке рим-світло на верхньому краї;
  - м'яка контактна тінь під предметом.
- **Силуети:**
  - ветклініка — медична валіза;
  - терміново — коло з хрестом;
  - ветаптека — флакон;
  - зоомагазин — пакет із кісточкою;
  - грумінг — ножиці;
  - перетримка — дім із місяцем;
  - притулок — дім із серцем;
  - решта — м'яка лапа.
- **Кольори лише з токенів** (`theme.css`, світла й темна теми). Градієнти визначено один раз у `<IconMaterialDefs />` у кореневому layout. Без них діє плаский запасний колір, тому іконка не зникає.
- **Нова іконка:** тіло, лінія, акцент, рим — без дрібних деталей. Перевірте при 24 px. Тест `serviceIconsV139.test.ts` перевіряє шари, відсутність жорстко заданих кольорів і корал лише для термінової категорії.
- Іконки дій (`PhoneIcon`, `RouteIcon`, `LocationIcon`…) мають ту саму палітру: сосна замість яскравої бірюзи, тепла тінь.

## 10. Предмети з теплої кімнати (з 1.40, замінює §9)

Іконки категорій — не UI-символи, а **маленькі фізичні предмети з тієї самої вечірньої кімнати**, що й на героєві.

- **Матеріал:** матова шавлієва кераміка (`--obj-hi / --obj-mid / --obj-lo`), освітлена лампою згори ліворуч (радіальна пляма світла, затінений бік знизу праворуч). Деталі — кремові й латунні (`--obj-detail-*`). Ручки — темна шкіра (`--obj-line`). Терміново — єдиний предмет із теракотової глини (`--obj-urgent-*`).
- **Без контурів.** Упізнаваність тримає силует; при 24 px суцільна форма читається краще за лінію.
- **Предмети:**
  - аптечка з кремовим хрестом — ветклініка;
  - глиняний жетон із хрестом — терміново;
  - банка з латунною кришкою і хрестом, вирізаним у етикетці, — ветаптека;
  - пакет із кісточкою — зоомагазин;
  - ножиці з латунними лезами — грумінг;
  - будиночок із теплим вікном-місяцем — перетримка;
  - будиночок із серцем — притулок;
  - лапа — решта.
- **Без «плиток застосунку».** Предмет лежить у власній невеликій калюжі світла лампи (`--obj-pool`), а не на піднятому квадраті. На темній шапці закладу — та сама калюжа, тепліша.
- **Нова іконка:** тіло, за потреби одна деталь, рим-світло; жодних дрібниць. Перевірте при 24 px і в обох темах.

## 11. Характер (з 1.40)

- **Головна думка:** коли тварині потрібна допомога в Києві, VetNear — спокійне, локальне, перевірене місце, яке допомагає зрозуміти, куди звернутися.
- **Два шляхи називаємо прямо:** терміновий — двері в героєві («Тварині зле? Знайти клініку»), плановий — «Планова турбота» над рядом послуг. Червоний — лише для першого.
- **Партнерам — запрошення, а не прайс:** теза («Ми збираємо мапу турботи Києва — разом із тими, хто її робить»), коротка відповідь, одна дія, тихе посилання на пілот. Без «Безкоштовно» як цінника, без чек-листів, без пакетних карток.
- **Картки закладів** — тепла поверхня слонової кістки, якої лампа торкається згори ліворуч, а не рядок каталогу.


## 12. Предмети і керування (з 1.41)

- **Предмети** (`ServiceIcon`, `RoomObject`) — для того, що є «річчю» у світі VetNear: категорії закладів, життєві сценарії (раптово зле → теракотовий жетон, тривога → штормовий ліхтар, знайшли тварину → жетон на нашийник, укус → щит), особисті записи (картка, календар). Завжди в калюжі світла (`--obj-pool`), ніколи на «плитці застосунку».
- **Гліфи** (`PhoneIcon`, `RouteIcon`, `FilterIcon`, `LocationIcon`, `VerifiedIcon`) — для керування: тонка лінія в кольорі тексту, без матеріалу. Кнопка — дія, а не предмет.
- **Стара soft-3D-родина видалена:** `SoftIcon` і дев'ять невикористаних іконок. Растрові плитки (`TileIcon`) лишилися тільки в розділах здоров'я/безпеки поза головною — наступні на заміну.
