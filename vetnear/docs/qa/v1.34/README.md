# VetNear 1.34 — перевірка реалізації

Дата: 17.11.2026. Перевірялася локальна production-збірка на `http://127.0.0.1:3003`, Node.js 24.22.1, Chromium 156.0.8078.79 через Playwright. Це перевірка вихідного коду та локальних сценаріїв; live deployment не змінювався.

## Збірка та тести

`npm run verify` завершився успішно: ESLint, TypeScript, **552 тести у 59 файлах**, `next build`. Повний [журнал](verify-v134.log). Нових runtime-залежностей немає.

Збірка попереджає про майбутнє припинення підтримки React 18 у Next.js 17. Поточна збірка Next.js 16.4.6 успішна; перехід на React 19 варто планувати окремо, перед наступним великим оновленням фреймворку.

## Перевірені шляхи

1. **Головна → пошук.** На ширинах 320, 390, 640, 768, 1024 і 1440 px немає горизонтального переповнення сторінки. Пошук і терміновий перехід видимі та доступні для натискання. GET-пошук працює без JavaScript і передає місто, вид тварини й послугу. Відмова зображення не блокує пошук.
2. **Головна → терміново.** Посилання веде прямо до клінік; не обіцяє підтверджений прийом зараз. Світловий ефект не рухає фото, вимикається паузою та reduced motion. Перевірено клавіатурний фокус.
3. **Заклад → збереження → повернення.** На 320, 390 і 1440 px збережена картка відкривається з контактними діями, переживає перезавантаження, видаляється і синхронізує іншу відкриту вкладку. Помилка квоти не показує успіх. Пошкоджений список не стирається автоматично; відновлення явне.
4. **Мої тварини → профіль.** Нейтральна монограма підтримує Unicode, справжнє фото зберігається. При пошкодженій колекції є повідомлення та повторна спроба, а не хибний порожній стан. Невдале створення не стирає введене, не змінює попередні дані та не переводить на екран успіху.
5. **Карта → район → заклади.** Клавіатура й дотик зберігають вибір; назва району є в кнопці переходу. На desktop перевірено рельєф 5 px під час наведення / 3 px для вибраного району. Reduced motion прибирає просторовий рух.

Групи містять різну кількість тверджень; їх не варто додавати до 552 автоматичних тестів як рівноцінні одиниці. Браузерні сценарії не зафіксували помилок сторінки. Допуск у 1 CSS px у внутрішньому рядку категорій враховує округлення ширини; переповнення самої сторінки не допускається.

Runner-файли збережені як точні артефакти цієї перевірки. Вони використовують Chromium і Playwright за абсолютними шляхами цього середовища; для повторення на іншому комп’ютері потрібно налаштувати ці шляхи та URL локального production-сервера. Playwright не додано до runtime-залежностей застосунку. Тестові записи тварин із runner-файлів є синтетичними.

## Що досліджено і що лишається гіпотезою

Перед змінами заново зафіксовано шлях 1.33: головна → пошук → заклад/сердечко → «Мої тварини». Реальний розрив — збереження без окремого місця повернення — усунуто сторінкою `/saved`. Перевірки сховища також підтвердили ризик хибного успіху та прихованого перезаписування пошкодженої колекції; ці сценарії закрито.

Тепліше світло, чіткіший Hero і стриманіший рельєф карти — дизайнерські рішення, підтримані експертним оглядом та рекомендаціями доступності. Їхній вплив на конверсію й повторні візити ще потрібно виміряти. [Джерела, обмеження і матриця рішень](../../RESEARCH_DECISIONS_V1_34_UK.md).

## Межі перевірки

- Не проводилися інтерв’ю, польові вимірювання Core Web Vitals або тестування на фізичних iPhone/Android. Емуляція touch у Chromium не замінює Safari.
- Міграції, платежі, live backend і повідомлення партнерам не запускалися. Сховища лишаються локальними й не синхронізуються між пристроями.
- Каталог лишається на рівні 90 місць; нових дзвінків для підтвердження даних не виконано. Пошукова доступність клініки не означає прийом зараз.
- Захист колекції тварин перевіряє базову структуру; це не повна схема валідації кожного історичного вкладеного поля. Вибір улюбленого ветеринара досі спирається на статичний каталог; нова колекція збережень використовує також опубліковані записи.
- Зовнішні карти, маршрути та актуальні години роботи залежать від постачальників і мають перевірятися після розгортання.

Перелік відмінностей від архіву 1.33: [change-manifest.json](change-manifest.json). Папки QA виключено з порівняння, щоб не включати сам маніфест і повторні знімки.
