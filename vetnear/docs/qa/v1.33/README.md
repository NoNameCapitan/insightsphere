# Перевірка VetNear 1.33

Перевірено локальну production-збірку у Chromium 156.0.8078.79 (headless), Node.js 24.22.1, на ширинах 320, 390, 640, 768, 1024 і 1440 px залежно від сценарію. Точну версію браузера дивіться в browser-version.txt.

- `verify.log`: повний ESLint, TypeScript, 525 тестів у 56 файлах і production build.
- `build-final.log`: повторна збірка після суто декоративної заміни символу посилання на SVG; scoped ESLint також пройдено.
- Дизайн: 4 групи перевірок, зокрема пошук без JavaScript, адаптивність, карта з клавіатурою/дотиком і reduced motion.
- Геолокація: 2 перевірки. Запит GPS лише за дією; відмова відкриває ручний ввід. Порожня відповідь геокодера не підставляє Київ; явний вибір адреси вмикає радіус. Відмову GPS і відповіді геокодера відтворено керовано.
- Пошук і контакти: 7 груп. Кнопка дзвінка та її текст перевірені на 320/390/640/768 px, включно з hit testing; панель не перекриває нижнє меню.
- Медкартки: 20 перевірок на 390/1440 px. Створення, редагування, населений пункт, нагадування, стабільний ICS, віджет головної та виконання. Тестові профілі збережені тільки у тимчасових браузерних контекстах.
- Події: 18 перевірок на 390/1440 px. Теми, локальне збереження, архів, неповні анонси, помилка квоти.
- Партнери: 16 перевірок на 390/1440 px. Пошук свого профілю, claim, локальна копія без POST, дублікати, операторський API без авторизації повертає 401.

Скриншоти переглянуто візуально. Pet-screen містить тестові дані; брендова сцена головної створена генеративно. Локальні перевірки не підтверджують реальну доступність клінік або доставку в живу БД. Фізичні iOS/Android, Safari, екранний диктор, живі інтеграції та польові Web Vitals залишаються передрелізними операційними перевірками. Плитки зовнішньої карти потрібно перевірити на домені публікації.

У вихідному коді є автоматизовані unit/DOM тести (`npm run verify`). JSON тут фіксує результати браузерного проходу; внутрішні шляхи запуску не є посиланнями для користувача.
