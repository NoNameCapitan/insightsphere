# VetNear v1.20 — generated visual prompts A–J

All final images intentionally contain **no embedded interface text**. Product
copy remains HTML so it stays sharp, accessible and localizable. The generated
assets live in `public/visuals/` and are animated by `GeneratedVisual.tsx` with
reduced-motion support.

## A — visual system atmosphere

Premium European pet-care med-tech background: soft mineral green and pearl
white field, refined teal translucent glass arcs, a restrained peach bloom and
organic contour lines. Wide landscape, negative space, matte glass, no text,
logos, people or busy decoration.

Output: `a-visual-system.webp`

## B — original soft-3D icon system

Ten distinct tactile objects: veterinary cross, medicine capsule, boarding
house with paw, grooming scissors with paw, urgent beacon, shelter, location
pin, phone, navigation arrow and verified check. Matte clay and frosted ceramic,
top-left light, transparent background, no labels or overlap.

Output: `b-icon-system.webp`

Output: `j-empty-state.webp`

## Motion rules

- `float`: 6.8-second vertical movement, maximum 5 px.
- `drift`: 9-second lateral/vertical movement, maximum 5 px.
- `tilt`: pointer-controlled 3D rotation, maximum 4 degrees.
- Motion never changes layout or hit targets.
- `prefers-reduced-motion: reduce` disables all generated-image animation.
