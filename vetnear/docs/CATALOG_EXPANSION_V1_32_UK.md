# Розширення каталогу VetNear v1.32

Дата перевірки публічних джерел: **2026-11-17**. Було **67**, додано **23**, стало **90** записів. Жодного дзвінка чи повідомлення закладам не здійснювали.

## Що додано

- 16 ветеринарних клінік/кабінетів, 4 ветаптеки, 1 незалежна ветеринарна лабораторія, 2 притулки.
- 10 точок у Києві та 13 у Київській області.
- Локальності: Київ — 10, Федорівка — 1, Гостомель — 1, Бровари — 2, Бориспіль — 1, Буча — 1, Ірпінь — 1, Біла Церква — 3, Вишгород — 2, Вишневе — 1.
- Реабілітація/неврологія: Neurocare та основна клініка «Айболит»; екзоти: Genesis, Genesis Care, ПрофіВет за заявами їхніх сайтів. Спеціалізацію не поширювали автоматично на інші філії.

## Метод і межі перевірки

- Назви, адреси та телефони взято з офіційних сайтів або державної сторінки установи.
- Координати взято з офіційних map markers / JSON-LD / конфігурації карти; для двох записів використано однозначне адресне геокодування. Центр viewport Google Maps не використовується як координата закладу.
- Усі 23 записи мають `source_checked`, `manual_unverified`, `verified: false`, `emergencyAvailable: false`, `rating: 0`. Це перевірка опублікованого джерела, а не підтвердження фактичного прийому сьогодні.
- `isOpen24_7: true` лише для Genesis Hospital, RealVet і Зоолюкс Бровари, де це прямо заявлено; ці записи не отримують статусу підтвердженої невідкладної допомоги.
- `workingHours: []` у ВетНова, Neurocare, Vet+Klinika та Гостомельського притулку: даних недостатньо або є обмеження/суперечність. Години для притулку «Сіріус» — години відвідування.
- Порожній `animalTypes` означає, що види тварин для конкретної точки не підтверджено, а не відмову в прийомі. Capability flags не піднімаються без джерела.
- Дані джерел, дата, метод координат, джерело графіка і особливі примітки збережені в `scripts/data/catalog-expansion-v1-32.json`. Генератор бере їх з цього файлу.

## Винятки та відхилені кандидати

- **Ласкавий Ветеринар:** офіційний iframe містив шаблонний marker `0x0:0x0` з хибною географією. Його відкинуто; назву, адресу Нове Шосе 14 та телефон звірено з конкретним Google marker. Це зафіксовано в coordinateEvidence.
- **ВетНова:** сайт має перерву прийому 10:00–11:00, попередній запис і нічні обмеження. Через це не позначено безперервний 24/7 прийом.
- **Vet+Klinika:** суперечність «щодня» / «Пн–Пт 10:00–18:00»; графік лишається невідомим.
- **ПрофіВет Біла Церква, НеоВетЛаб, державна лікарня Вишневе:** координати будинку; маршрут за офіційною адресою, вхід потребує уточнення. Графік державної установи не гарантує клінічний прийом у кожну хвилину.
- **Айболит, Стуса:** окремий ветеринарний кабінет при маркеті; не успадковує хірургію/лабораторію/реабілітацію головної клініки. Спільний домен мережі не створює дубліката за різних адрес, телефонів і map markers.
- **Ветаптека Укрзооветпромпостач, Васильківська 16:** збігається адреса зі старою клінікою ВетПро, але інша офіційна організація, категорія, сайт і телефон.
- **VetCare, Гмирі 4:** не додано: телефон збігається зі старим ВетПро Драгоманова 31В. Потрібне з’ясування переїзду/зв’язку перед створенням другого запису.
- **Велика Ведмедиця:** офіційні сторінки мають суперечливі години. У цю партію не включено без додаткової перевірки координат/графіка.
- **VetMedical:** конфлікти адрес і карта іншого закладу; відхилено. **PetVet:** сайт 429, достатніх координат не зібрано.
- **Притулки:** статус не обіцяє вільних місць; «Сіріус» прямо повідомляє про переповнення. Гостомельський притулок дає точну геолокацію й орієнтири без номера будинку; номер не вигадано.

## Відтворюваність і перевірки

```bash
npm run build:places
npm run check:places
npx vitest run src/lib/__tests__/catalogExpansion.test.ts src/lib/__tests__/placesInSync.test.ts src/lib/__tests__/dataset.test.ts
```

Генератор перевіряє унікальність ID та адреси в межах міста/категорії. Тест партії перевіряє evidence URLs, source dates, географію області, відсутність phone/emergency claims, невигадані рейтинги, збереження невідомого графіка й відсутність дубля того самого провайдера за адресою.

## Прибрано синтетичні legacy defaults

Окремим проходом перевірено логіку старих 67 записів. Збережено ID, назви, адреси, контакти та явно документовані винятки; прибрано автоматичні припущення за категорією.

| Ненульовий рейтинг | 64 | 0 | Оцінки обчислювалися з індексу запису, без джерела відгуків |
| Заповнений графік | 67 | 6 | Решта 61 були шаблонами категорій |
| Заповнені види тварин | 67 | 4 | Збережено MAVET, А-Вет, його аптеку й dogs-only Dambo |

| Хірургія / УЗД | 33 / 33 | 5 / 5 | MAVET, А-Вет і три муніципальні клініки |
| Рентген | 33 | 1 | Збережено джерельно описаний А-Вет |
| Наявність ветаптеки | 37 | 2 | А-Вет та його окрема аптека |
| Автоматична доставка / самовивіз | 23 / 27 | 0 / 0 | Немає доказу для кожної філії |

Збережені винятки: графік MAVET 09:00–21:00; муніципальні клініки 09:00–19:00 та їхні правила тривоги; А-Вет і його аптека 24/7 за джерелом; нічний лікар, кисневі бокси та автономне живлення А-Вет. Екстрені статуси не підвищено. `false` у capability flag означає, що можливість не підтверджена для фільтра, а не доведену відсутність обладнання. `[]` у графіку/видах тварин означає невідомо.

## Що ще потребує роботи

Старі записи не переатестовано дзвінками; частина координат лишається приблизною, а контактні дані — історичними. Поточні 90 точок не слід називати 90 підтвердженими дзвінком закладами. Потрібні планова перевірка актуальності, адрес/входів та окрема ручна верифікація невідкладного прийому.
