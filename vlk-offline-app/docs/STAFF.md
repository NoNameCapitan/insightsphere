# ВЛК Offline — коротка інструкція для персоналу

**Перший запуск:** установіть Node.js 24 LTS, розпакуйте архів і запустіть
`START-WINDOWS.cmd`. На macOS/Linux — `bash start-local.sh`. Першого разу
потрібен інтернет для встановлення. Створіть адміністратора за підказками
у вікні запуску. Потім відкрийте **http://localhost:3000**.

**Подальша робота:** запускайте той самий файл і залишайте вікно відкритим.
Інтернет більше не потрібен — мережу можна вимкнути назавжди. Для кількох
кабінетів мають працювати локальна мережа та комп'ютер-сервер.
Дані лежать на його диску.

**Якщо внизу екрана з'явилося червоне попередження** «Локальний сервер не
відповідає» — не закривайте вкладку з незбереженою формою. Текст залишається
на екрані. Перевірте вікно запуску на комп'ютері-сервері й повторіть
збереження. Інтернет для цього не потрібен.

Адміністратор спочатку створює окремі логіни працівників. Лікарю призначає
спеціальність; одну людину можна зробити, наприклад, і стоматологом,
і заступником голови. Усі паролі — щонайменше 12 символів.

| Хто                  | Що робить                                                                                         |
| -------------------- | ------------------------------------------------------------------------------------------------- |
| Реєстратор           | «Новий прийом» → знайти / внести особу → направлення → спеціалісти → зберегти → друк талона       |
| Лікар                | Відкрити картку зі своєї черги → огляд, МКХ, стаття, висновок → зберегти чернетку або підтвердити |
| Секретар             | Перевірити всі огляди → підготувати повний підсумковий діагноз і постанову                        |
| Голова / заступник   | Після всіх оглядів перевірити та підтвердити підсумок                                             |
| Оператор перенесення | «Перенесення» → копіювати поля → вставляти в Helsi → звіряти й позначати внесене                  |

**Перенесення без передруковування:** біля кожного поля є «Копіювати».
Вставляйте текст у потрібне поле Helsi через Ctrl+V. Цілий огляд можна
скопіювати одним блоком. Коди в довідниках МІС і збереження запису перевіряйте
окремо. Це допоміжний буфер, а не автоматична API-синхронізація.
Частковий прогрес можна зберегти й продовжити пізніше.

**Друк:** талон та робоче зведення; у вікні друку браузера можна обрати
«Зберегти як PDF». Офіційні бланки ВЛК оформлюйте за вимогами установи:
робоче зведення не є затвердженою формою і не містить КЕП.

**МКХ:** вбудований каталог eHealth — історичний знімок 2019 року.
Лікар звіряє код із актуальним довідником; адміністратор може імпортувати
каталог установи. Є ручне введення коду з документа.

**Якщо зв'язок із сервером зник:** не закривайте вкладку й не оновлюйте
браузер із незбереженим текстом. Відновіть сервер / мережу та повторіть збереження.
Якщо вхід закінчився, увійдіть у новій вкладці, поверніться до огляду й збережіть.

**Щодня:** уповноважений працівник запускає `npm run backup` на сервері,
задає пароль копії та переносить зашифрований файл на резервний носій.
Пароль зберігайте окремо. Експорт JSON / CSV / XLSX не замінює резервної копії.

Повна інструкція, мережеві налаштування, Docker і відновлення — у `README.md`.
