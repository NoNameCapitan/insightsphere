# VLK v28 — клінічне компонування

База: VLK-Navigator-402-v27.1-clinical-polish(2).zip. Перевірка: 20.09.2026.

## Реалізовано

- Пункти перед блоками «Включено», повного пояснення та загальних ТДВ. У розгорнутому пункті збережені дослівні тексти й усі дії; додана контекстна кнопка «Звірити ТДВ».
- Назви узгоджені: «Зведення», «Переглянути зведення»; мобільні вкладки «Список / Читання / Зведення». Порожнє зведення має інструкцію та кнопку повернення до читання.
- При 1024–1279 px список залишається ліворуч, читання або зведення праворуч. Від 1280 px — три колонки; ширина правої залишилася 228 px.
- Скорочені дублювання шапки; дати корпусу й записаної перевірки збережені, повне пояснення доступне у title. Посилання на джерело доступне клавіатурою й має текстову назву на телефоні.
- У результатах пошуку назва переноситься, МКХ і причина збігу мають окремі рядки. Пошуковий алгоритм не змінений.
- Заголовки пунктів переносяться до трьох рядків; повний текст доступний розгортанням. Довгі назви у зведенні переносяться.

## Вимірювання до / після

Один сценарій: лікар → стаття 39, запит «стаття 39», пункти згорнуті, світла тема, порожнє зведення.

| 390×844 | До | Після |
|---|---:|---:|
| Шапка | 127 px | 107 px |
| Стрічка редакції | 107 px | 45 px |
| Початок області прокручування статті | 515.39 px | 416.39 px |
| Висота області читання | 320 px | 419 px |

Приріст області читання: 99 px / 31%. Виміряно clientHeight фактичного `.article-content`. Це не висота всього центрального panel.

Скріншоти before/after-desktop: 1363×936. Before/after-mobile: той самий браузер із реальною програмою в iframe 390×844, сіре поле та селектор — зовнішній QA-стенд. Не ізольований renderer, не емуляція фізичного телефона. Стенд видалено з архіву.

## Розгортання

Архів містить код, lockfile, вихідні assets і цей звіт; без node_modules, build-каталогів, кешів, QA-стенда, логів та локальних env. Для Next/Vercel: `npm ci`, `npm run build:next`, `npm run start:next`. Для наявного Vinext/Cloudflare шляху: `npm ci`, `npm run build`; конфігурація деплою збережена. Публікацію не виконано. Перед клінічним використанням перевірте системний друк/PDF і офлайн-режим на цільовому пристрої.
