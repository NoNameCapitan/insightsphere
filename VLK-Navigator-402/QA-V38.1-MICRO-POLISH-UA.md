# v38.1 — чотири точкові UI-правки

База: остання перевірена v38. Збережено категорії огляду та всі перехресні
посилання останніх оновлень; повернення до старих v36-архівів не було.

1. **Підказка про шпильку.** 11 px, спокійний сірий `--ink-muted`.
   Показується лише протягом перших трьох завантажень із порожнім швидким
   доступом. Лічильник `vlk_pin_hint_seen` зберігається локально.
   Повернення зі статті на головну в тому самому завантаженні не збільшує
   лічильник. Наявні закріплені й часті статті не приховуються. Якщо браузер
   блокує localStorage, застосунок не падає, але між візитами ліміт зберегти неможливо.
2. **Кнопки статті.** «Порівняти пункти» — службовий синій фон і контрастний
   світлий текст. «Детальне пояснення» — стриманий фон та виразніша межа.
   Розміри, підписи, порядок і обробники дій збережені.
3. **Бейджі.** Фактичний контраст у темній темі достатній: червоний 6,88:1,
   бурштиновий 6,78:1, зелений 6,85:1. Палітру та логіку не змінено.
   У світлій темі також усі три стани мають контраст не нижче 4,5:1.
4. **Офлайн-статус.** Зменшено тільки повідомлення «Офлайн-копія готова»
   після першої інсталяції: близько 184×36 px замість 356×54 px, шрифт 12 px,
   спокійна поверхня, без тіні. Повідомлення про оновлення й помилки,
   індикатор мережі, кешування та офлайн-робота залишилися без змін.

Браузерні сценарії виконано з увімкненим `prefers-reduced-motion`.
Нових анімацій не додано. Скриншоти до/після та вимірювання наведено в
окремому звіті `VLK-v38.1-QA-UA.html`.

Особливість наявного тестового процесу: повторний vinext build може залишити
старі assets у `dist`, що впливає на перевірку офлайн-маніфесту. Остаточний
`npm test` виконано з чистим `dist`; build-скрипти й тести не змінювалися.

Використано реальний production Chromium. Фізичні мобільні пристрої,
Safari та публікація у Vercel не перевірялися. Нових залежностей немає.
Усі наявні тести збережено; окремих source-тестів, що дублюють CSS, не додано.
Поведінку лічильника та кнопок перевірено в браузері.

## Змінені файли

- `components/vlk/quick-access.tsx` — обмеження показу підказки.
- `app/page.tsx` — готовність локальних налаштувань перед показом підказки.
- `components/sw-register.tsx` — клас оформлення лише потрібного повідомлення.
- `app/globals.css` — підказка, дві кнопки, компактне офлайн-повідомлення.

Дизайн-сітка, Plex Sans, усі модулі `lib/`, нормативні тексти, пояснення,
категорії, МКХ, ТДВ, пошук, закріплення, формати сесії, анімації,
`public/sw.js`, package.json і lockfile збережені.

## Запуск

Node.js >=22.13.0. `npm ci`, `npm run build:next`, `npm run start:next`.
Для Vercel: корінь — папка з package.json; Build Command — `npm run build:next`.
`npm run build` залишається vinext/Cloudflare збіркою.
ZIP без node_modules, build-кешів, приватних .env, логів та вкладених архівів.
