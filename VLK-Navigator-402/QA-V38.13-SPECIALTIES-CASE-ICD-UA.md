# VLK Навігатор v38.13 — інструменти спеціальностей, кольоровий «Випадок» і МКХ

## База та межі

База — доставлений v38.12, SHA-256
`0390619e0bda470420d07d56c0a6347ee5998ae24dd48b4a65b78d3dae33df22`.
Робоча копія і повторно прикріплений архів побайтово відповідали цій базі.

Дослівні статті, результати пунктів, пояснення, ТДВ, якорі й базовий механізм
оцінки «Випадку» не переписано. Редакція нормативного корпусу — **22.08.2025**.
Технічна перевірка не є підтвердженням усіх чинних норм на будь-яку майбутню
дату або незалежною клінічною валідацією повного каталогу МКХ.

Деплой і push не виконувалися. Архів призначений для запуску й подальшої
перевірки власником у своєму браузері.

## Короткий робочий шлях

1. Оберіть лікаря або знайдіть статтю / МКХ
2. За потреби відкрийте профільний розрахунок; результати з’являються одразу
3. Кнопка статті з калькулятора відкриває відповідний нормативний текст,
   **без автоматичного вибору пункту**
4. У «Випадку» введіть підтверджені пункти та, за потреби, зріст / вагу
5. Звірте окремо формулювання Розкладу й підстави ТДВ; «Чому» відкриває деталі

Не додано дев’ятої спеціальності або довільних діагностичних шкал. У лікарів,
для яких у погодженому переліку немає належного арифметичного інструмента,
залишається спільний короткий шлях через МКХ, статтю, пояснення та «Випадок».

## Розрахунки

### Терапевт

Збережено прямі кнопки **ІМТ**, **ММЛШ**, **ІММЛШ**. У компактному «Ще 3»:

- **рШКФ:** креатинінова CKD-EPI 2021, вік від 18 років, явно обрана стать,
  креатинін у мкмоль/л або мг/дл; перерахунок мкмоль/л ÷ 88,4
- **FIB-4 / APRI:** лабораторні значення, без автоматичної стадії фіброзу;
  верхню межу АСТ необхідно ввести з лабораторії, 40 не підставляється
- **Спірометрія:** ОФВ1 / ФЖЄЛ, ОФВ1 від належного, необов’язкова зміна
  ОФВ1 після бронхолітика від вихідного значення у мл та відсотках

### ЛОР

**PTA4** для кожного вуха окремо:
`(T500 + T1000 + T2000 + T4000) / 4`, dB HL.
Чотири пороги одного вуха достатні для його результату; друге не блокує
обчислення. Нульові й від’ємні пороги допустимі. Blank, NR або >межа
не перетворюються на нуль або довільний максимальний поріг.

### Офтальмолог

**Рефракція** для OD і OS окремо:
`M1 = Sph`, `M2 = Sph + Cyl`, `Δ = |Cyl|`.
Знак циліндра зберігається; вісь не потрібна для цих трьох чисел.
Меридіани не усереднюються для №402, діоптрії не перетворюються у гостроту зору.

### Хірург

- **Виміри кінцівок:** різниця виміряних довжин `|ліва − права|`, з явною
  назвою коротшої сторони; верхні / нижні кінцівки не змішуються
- **Рухи · таблиця 14:** вибір конкретного рядка, запис виміряного кута й
  показ дослівних довідкових чисел; жодної автоматичної класифікації
- **рШКФ:** той самий перевірений інструмент для наявної профільної статті 66

Кути таблиці 14 не переводяться у сучасний метод нейтрального нуля.
Наприклад, дослівна норма згинання ліктя у таблиці — **40°**, розгинання —
**180°**. Застосунок не порівнює з ними автоматично запис 0/150°.

## Формули та контрольні приклади

### CKD-EPI 2021

`142 × min(Scr/k,1)^α × max(Scr/k,1)^−1,200 × 0,9938^вік × S`

- Scr у мг/дл
- Жінки: k=0,7; α=−0,241; S=1,012
- Чоловіки: k=0,9; α=−0,302; S=1
- Результат: мл/хв/1,73 м²
- Немає коефіцієнта раси чи ваги

| Вхід | Результат |
|---|---:|
| Чоловік, 50 років, 1 мг/дл = 88,4 мкмоль/л | 91,6914786098333 |
| Жінка, 50 років, 1 мг/дл | 68,63349665880087 |
| Чоловік, 40 років, 0,9 мг/дл | 110,72559960355491 |
| Жінка, 40 років, 0,7 мг/дл | 112,05430679879757 |
| Чоловік, 70 років, 2 мг/дл | 35,24299672901596 |

№402 називає CKD-EPI, не визначаючи рік; 2021 чітко названо як обраний
клінічний метод. Оцінка призначена для дорослих зі стабільним креатиніном.
Гострі зміни та нетипова м’язова маса можуть знижувати точність. Один результат
не встановлює ХХН.

### Печінка

`FIB-4 = вік × АСТ / [тромбоцити × √АЛТ]`

`APRI = 100 × (АСТ / верхня межа АСТ) / тромбоцити`

АСТ / АЛТ / верхня межа — Од/л; тромбоцити — ×10⁹/л.
50 років, АСТ 40, АЛТ 25, тромбоцити 200, верхня межа АСТ 40 →
FIB-4 **2**, APRI **0,5**. За АСТ 0 і решти валідних значень обидва індекси 0.

Індекси не дають автоматичного F4. Гострий стан, позапечінкові причини змін
АСТ / тромбоцитів та контекст захворювання впливають на інтерпретацію.
Пороги для MASLD не переносяться автоматично на вірусні гепатити.

### Інші контрольні приклади

- PTA4: 10 / 20 / 30 / 40 → **25 dB HL**;
  −10 / 0 / 5 / 15 → **2,5 dB HL**; 0 / 0 / 0 / 0 → **0**
- Рефракція: S −4, C −2 → **−4 / −6**, різниця 2;
  S −6, C +2 → **−6 / −4**, різниця 2;
  S +2, C −4 → **+2 / −2**, різниця 4
- Спірометрія: ОФВ1 до 2 л, ФЖЄЛ 4 л, належний ОФВ1 4 л, ОФВ1 після
  2,3 л → **50%**, **50%**, **+300 мл**, **+15% від вихідного**
- ОФВ1 до 2, після 1,8 → **−200 мл / −10%**; негативний приріст не обрізається
- 3,6 / 3 належного → **120%**; результат не обмежується 100%
- Довжини 90 / 87,5 см → **2,5 см**, права коротша; 85 / 85 → **0 см**

## Колір і залежності «Випадку»

Вікно показує два окремі рівні:

1. **Розклад / категорія огляду — кожен пункт окремо**
   - Зелений: формулювання придатності конкретного пункту
   - Жовтий: визначені види служби або тимчасовий стан із власним підписом
   - Червоний: формулювання непридатності з явною сферою застосування
   - Сірий: порожня / невідома відповідь, потрібна графа або інше уточнення
2. **ТДВ — окремі вимоги до конкретних призначень**
   - Позначки, умови, числові межі й пропуски джерела не зливаються
   - Зелений не з’являється за невідомої графи, невизначеної категорії,
     невідповідного результату Розкладу або без доданих підтверджених пунктів
   - Числові критерії, які виконано без достатнього Розкладу, залишаються
     нейтральною перевіркою окремих даних, не забороною і не дозволом

«Визначені види служби» — короткий навігаційний підпис. Повне формулювання
відкривається натисканням. Скасовану категорію «обмежено придатний» не
повернуто. Загальна постанова ВЛК не формується; найсуворіший пункт не
приховує інші невідомі або порожні підстави.

Контрольні залежності:

- **39а:** явно показана червона норма Розкладу навіть без окремого рядка ТДВ
- **28б + інший член екіпажу + 180 см / 80 кг:** адресна умова для водія не
  застосовується, але це не стає зеленим загальним допуском
- **40в / 13в:** відсутні рядки ТДВ; не успадковуються позначки 40б / 13б
- **73б:** графа I порожня, графа II має свій результат; I–III не плутаються
  з графами ТДВ 1–12
- **82а / 82б:** порожні клітинки потрібних граф не стають зеленими
- **Контракт, 14б:** непридатність до контракту показана зі своїм підписом;
  загальний текст Розкладу зберігається окремо
- **Вступ, ТДВ 9/10:** вимога вступу не переноситься на всі 12 призначень
- Водій / екіпаж і КРП / інший чинник змінюють тільки адресні підстави
- Точні межі зросту й ваги включні; вихід за числову межу не вигадує
  позначку «НП» там, де у таблиці її немає

## Дані та валідація вводу

- Калькулятори і «Випадок» зберігають дані лише в пам’яті вкладки
- Немає мережевих запитів, URL-параметрів або записів сховища з введеними
  вимірами; немає поля ПІБ
- Завершення сесії та міжвкладкове очищення скидають усі ці значення
- Порожнє поле — пропуск, не нуль; неправильне залежне поле прибирає
  попередній результат
- Кома / крапка, валідні знаки й доменні нулі підтримуються явно
- Зміна одиниць креатиніну, етапу спірометрії або виду парних кінцівок
  очищає пов’язані поля, щоб старе число не отримало інше значення
- Проміжне округлення не використовується. Довільні клінічні hard caps не
  додані. Дані не перетворюються автоматично у пункт статті
