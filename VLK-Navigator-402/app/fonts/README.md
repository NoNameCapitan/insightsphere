# Локальні шрифти VLK

Оригінальні TTF із репозиторію google/fonts. Файли не модифіковані;
змінено тільки назви файлів для читабельних локальних шляхів.
Точні URL, розміри й SHA-256 наведені в `sources.json`.
Супровідні ліцензії: `ibmplexsans-OFL.txt`, `ibmplexmono-OFL.txt`, `ptserif-OFL.txt`.

IBM Plex Sans — інтерфейс (400–700); IBM Plex Mono — коди (400/500/600);
PT Serif — нормативний текст (400/700, normal/italic).
Файли з повними наборами символів містять українські Ґ/Є/І/Ї.

Підключення — `app/layout.tsx`, `next/font/local`. Жодного запиту до
Google Fonts під час збірки чи читання інтерфейсу. Шрифти копіюються
збирачем у версійні ресурси й потрапляють до офлайн-маніфесту.
