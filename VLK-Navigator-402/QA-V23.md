## Межі й особливості репозиторію

- Корпус редакції 22.08.2025 збережено без правок. Цей випуск не підтверджує чинність редакції на сьогодні.
- Графа I/II/III залишається контекстом для прямих офіційних згадок; нових правил визначення придатності немає.
- Поведінку service worker перевірено автоматичними тестами; офлайн-встановлення цієї версії на реальному телефоні не перевірялося.
- Діалог системного друку та PDF-вивід не проходили браузерної перевірки. Резервне копіювання при відмові API перевірено модульно; браузер дозволив основний шлях.
- `npm test` повторно виконує Vinext build. Для окремих кроків CI слід запускати `npm run build`, потім `node --test tests/*.test.mjs`.
- Тест офлайн-маніфесту потребує актуальної папки `dist/client`; тести слід виконувати одразу після збірки, без паралельного перезаписування її файлів. При повторному запуску зі старими ресурсами виникла невідповідність маніфесту; повна повторна збірка та 108 тестів пройшли.
- У початковому архіві немає окремого npm-скрипта typecheck: використано `npx tsc --noEmit`.
- Архів не містить залежностей, кешів, тимчасового responsive-harness або готових build-артефактів. Після розпакування потрібні `npm ci` і збірка.
