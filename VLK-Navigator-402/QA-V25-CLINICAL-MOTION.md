# VLK Navigator 402 — Visual + Motion Pass

Дата перевірки: 16.09.2026. Основа: наданий `VLK-Navigator-402-v24-redesign(1)(1).zip`.

## Аудит перед реалізацією

Проєкт збережено на Next.js 16.2.6, React 19.2.6, TypeScript, Tailwind CSS 4 та vinext/Vite. App Router, основний маршрут `/`. Tailwind налаштований через CSS (`@theme inline` у `app/globals.css`), а не окремий `tailwind.config`. Тема — `next-themes`, клас `.dark`, ключ `vlk-theme`. Базові компоненти — `components/ui`, профільні — `components/vlk`.

| Зона | Реалізація |
| --- | --- |
| Головна, specialty selection, картки лікарів | `app/page.tsx`, `components/vlk/specialty-icon.tsx` |
| Header та емблема | `app/page.tsx`, `components/vlk/command-brand.tsx` |
| Ліва навігація, фільтри, список статей | `app/page.tsx` |
| Центральна стаття, пункти, графи, ICD | `app/page.tsx`, `highlighted.tsx`, `explanation-document.tsx` |
| DiagnosisCart та StateSummary | Inline-секції `app/page.tsx`; окремих компонентів із цими назвами немає |
| Пошук та відбір пунктів | `lib/vlk-search.ts`, `lib/vlk-selection.ts`, виклики в `app/page.tsx` |
| ТДВ і нормативні таблиці | `tdv-dialog.tsx`, `explanation-document.tsx`, protected-модулі `lib/vlk-tdv*`, `lib/vlk-explanation-tables.ts` |
| Мобільні вкладки та діалоги | `workspace-tabs.tsx`, `dialog-content.tsx`, адаптивні правила CSS |
| Палітра, типографіка, transitions | `app/globals.css`, `theme-controls.tsx` |

Основні пороги: 640, 768, 1024, 1280 px. Від 1280 px залишено три колонки; нижче — існуючі вкладки «Статті / Стаття / Зведення». Вибір спеціальностей на вузькому екрані — дві колонки.

Protected zones визначено до правок: нормативний корпус і пояснення, статті та пункти, графи, ICD та винятки, ТДВ, правила результатів, пошукова семантика, specialty mapping, кошик/зведення, persistence, API/data layer, auth, routing, існуючі тести та build-конфігурація.

## Реалізовано

- Узгоджені світлі й темні поверхні, бордери, радіуси, темпи переходів і контраст пошукового маркера.
- Спокійніший header, прибраний декоративний фон усередині робочих статей, статична стрічка редакції.
- Компактні картки спеціальностей з єдиною системою SVG-контурів і кольорів для обох тем.
- Виразніші номер статті, літери пунктів, статуси та активний пункт; нормативний текст залишається дослівним, із читабельним розміром і міжряддям.
- Локальний ряд контексту «Стаття → Пункт → Графа» біля вибраного пункту. Він відображає поточний вибір і нічого не обчислює.
- Візуальний зв’язок елементів зведення, коротка реакція рядка, лічильника та результату на додавання. Live-region результату збережений зі стабільним контейнером.
- Кошик на телефоні оформлений як нижня панель; його дії, чекліст, чернетка й експорт залишилися на місці.
- У ТДВ покращені шрифт, межі, hover рядка та мобільний заголовок. Збережені повна таблиця, 12 граф, sticky-заголовок і перша колонка. На телефоні прокручується таблиця, а не вся сторінка.

## Motion та ілюстрації

Новий `components/vlk/clinical-motion.tsx` керує лише декоративним DOM-станом. Одночасно активний один логотип або одна specialty card. Hover, keyboard focus і touch не затримують навігацію. Після виходу — м’яке повернення за 180 мс. Немає таймерів, циклів, нової бібліотеки або збереження motion-стану.

| Спеціальність | Візуал і рух | Повна послідовність |
| --- | --- | --- |
| Терапевт | Стетоскоп: локальний пульс і короткий ECG-слід | 1,9 с |
| Хірург | Скальпель: точний рух леза, відблиск і лінія шва | 1,9 с |
| Невролог | Мережа з 9 вузлів: центральний імпульс, аксон, три хвилі відгалужень до периферії | 2,35 с |
| Психіатр | Контрольовані зв’язки, спокійне розкриття структури та синхронний пульс вузлів | 1,8 с |
| Офтальмолог | Рух і звуження зіниці, м’який рух контуру, короткий відблиск | 1,9 с |
| ЛОР | Звукові хвилі з подальшою реакцією внутрішнього контуру вуха | 2,0 с |
| Стоматолог | Зуб: малий нахил, відблиск емалі й імпульс усередині пульпи | 2,0 с |
| Дерматовенеролог | Поперечний зріз шкіри: послідовне відділення та збирання трьох шарів | 2,05 с |

Окремі фази займають 800–1400 мс; затримки складають їх у довшу цілісну послідовність. Це зберігає чинний контракт тестів для тривалості фаз. Нові спеціальності не додавалися: наданий mapping містить саме ці вісім.

Емблема: цикл змії 2,8 с. Окремо рухаються три сегменти корпусу, шия/голова та язичок; голова наближається до чаші, піднімається й повертається. Обертання всієї емблеми прибране. Оригінальний PNG не змінений, сегменти виділені через SVG clipping. Розміри великої емблеми з наданої версії збережені без роздування header.

`prefers-reduced-motion` вимикає декоративні CSS-анімації та JS-повернення. Інформація, вибір і доступ до функцій залишаються доступними без руху. Постійний фоновий knowledge graph не додано: він необов’язковий у brief, а пріоритет віддано читанню та одному motion-сигналу.

Немає видалених вихідних файлів. Обробники клінічних дій та обчислення в `app/page.tsx` залишилися тими самими; зміни там стосуються render-розмітки.

## Особливості репозиторію та межі перевірки

- Для Next/Vercel використовувати **`npm run build:next`**, не голий `next build`: штатний скрипт додає офлайн-маніфест. Для Vinext/Cloudflare — **`npm run build`**. Існуючий `vercel.json` це вже враховує.
- `npm test` сам запускає Vinext build; частина тестів читає `dist/client`. Самого Next build для цих тестів недостатньо.
- Один повторний прогін після серії preview/build виявив у локальному `dist` зайві чанки від попередніх збірок: manifest check не пройшов. Після зупинки preview й видалення тільки generated `dist` повний `npm test` пройшов 122/122. Дані, тести й build-скрипти для цього не змінювалися. Для CI використовувати чистий checkout; не запускати кілька build/preview-процесів у спільному output-каталозі.
- Build-обгортки використовують Bash і GNU `timeout`; заявлена версія Node — `>=22.13.0`. Немає окремого `typecheck` script — виконано `npx tsc --noEmit`.
- Vinext друкує інформаційне повідомлення про невизначену статичним аналізатором класифікацію `/`; обидві збірки завершилися успішно. Попередження npm про `http-proxy` належить середовищу перевірки.
- Safari/iOS, фізичні touch-пристрої й повний screen-reader audit не перевірені. Reduced motion перевірено чинними тестами й оглядом CSS/JS, без окремого браузерного прогону із системним режимом Reduce Motion. Це не заявка на повну WCAG-сертифікацію.

ZIP містить вихідний проєкт для штатного deployment: без залежностей, `.next`, `dist`, runtime-кешів, тестових HTML-стендів, логів, локальних env-файлів і секретів. Нових залежностей або міграцій немає.
