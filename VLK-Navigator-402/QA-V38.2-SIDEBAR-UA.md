# v38.2 — простір для списку статей і читання

База — v38.1, без повернення до старих архівів.

## Реалізовано

- Три незалежні секції ліворуч: «Спеціальність», «Параметри огляду»,
  «Фільтри пунктів». Початково згорнуті; відкриваються натисканням,
  Enter або Space. Вибрана спеціальність, категорія, графа Розкладу,
  призначення ТДВ та активні фільтри видимі у коротких підсумках.
- Налаштування займають не більше 52% висоти панелі; мають власне
  прокручування. Список статей прокручується незалежно. Усі статті
  залишаються доступними, збережено клавіші ↑/↓/Home/End/Enter.
- Ущільнено лише заголовок статті: відступи, номер, назву й рядок МКХ.
  Повна назва доступна; довгий заголовок прокручується, а не обрізається.
  Нормативний текст у зоні читання та кнопки дій не зменшувалися.
- Згортання не скидає значення й не змінює правила результатів.
  Налаштування відкритості — лише UI; нових ключів localStorage немає.

## Вимірювання у production Chromium

Стаття 14, спеціальність «Психіатр», однаковий початковий стан.

| Viewport | Список до → після | Заголовок до → після |
|---|---:|---:|
| 1366×768 | 74 → 369 px | 156 → 133 px |
| 1440×900 | 206 → 501 px | 156 → 133 px |
| 1024×768 | 246 → 337 px | 156 → 133 px |
| 1093×614 | 177 → 190 px | 156 → 133 px |
| 390×844 | окрема вкладка «Список» | 205 → 192 px |

1093×614 — окремий CSS viewport для невеликої робочої області;
це не перевірка реального масштабування Windows/браузера.
На 1366×768 навіть з усіма розгорнутими секціями й довідкою для списку
залишається не менше 250 px.
