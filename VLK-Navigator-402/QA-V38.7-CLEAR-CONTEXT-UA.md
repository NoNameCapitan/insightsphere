## Що стало простішим

- У панелі статті одразу видно **«Пояснення»** та офіційне джерело №402.
  Порівняння, закріплення, часті статті й перемикання вперед/назад зібрані
  в один блок **«Порівняння та інші дії»**, початково згорнутий.
  Функції збережено. «Мої статті» та «Закріпити/Відкріпити» мають текстові
  підписи. Після перемикання статті блок залишається відкритим, доки його
  не згорнути; повторні переходи не потребують зайвого розкриття.
- У меню вибору I/II/III видно **повні наявні описи граф**, без переказу
  нормативного тексту. Саме поле залишається коротким. Окрема видима
  підказка розрізняє категорію огляду, графу Розкладу та призначення ТДВ.
- Коли результат вибраного пункту залежить від невибраної графи, є дія
  **«Перейти до вибору графи I–III»**. Вона відкриває потрібні параметри
  й переводить фокус до поля. Для вступу до ВВНЗ без призначення або
  зі старим несумісним призначенням доступне **«Уточнити призначення ТДВ»**.
  Відкривається також вкладений блок ТДВ, тож поле не лишається прихованим.
- Перехід до параметрів зберігає запит, статтю та пункт. Підказка нічого
  не обирає автоматично. Для пунктів із однаковим результатом за графами
  невибрана графа не перетворюється на нову перешкоду.
- Збережені зелений банер, графітова шапка, щит із тризубом, власна емблема,
  світла/темна теми, розмір тексту, обмеження руху й цілі дотику від 44px.
  Нових екранів, турів або функціональних режимів не додано.

### Перевірені DOM-сценарії

Повний React Home монтувався у jsdom із реальними даними й обробниками:

1. Стаття 82а без графи → перехід до правильного поля в логіці ширин
   390/768/1023/1024/1366 → графа II: порожня клітинка залишається порожньою
2. Стаття 73б, графа II: загальний результат дослівний; після вибору контракту
   зберігається окрема норма категорії, а графа I недоступна для цього вибору
3. Вступ до ВВНЗ без ТДВ → відкриття обох потрібних блоків → фокус поля →
   ТДВ 9; стаття, пункт і запит збережені
4. Повні описи всіх трьох граф у меню, коротке значення закритого поля
5. Початково згорнуті інструменти; закріплення/відкріплення; відкриття/закриття
   частих статей і порівняння; повторне перемикання вперед/назад
6. Пряме відкриття пояснення й пошук «Таблиця 5»; збережений глобальний запит
7. Зміна й локальне збереження світлої/темної теми

Next Image замінено простим img; matchMedia, ResizeObserver і геометрія
були тестовими. Це перевірка DOM та стану, **не перевірка піксельного вигляду,
реального вікна браузера, фізичного фокуса або скролу на пристрої**.

## Обмеження

Реальне браузерне/мобільне візуальне QA: **BLOCKED / NOT RUN**.
Раніше cloud browser відхилив локальне preview з `net::ERR_BLOCKED_BY_CLIENT`;
незмінне обмеження не обходилося. Нових скриншотів застосунку немає.
Safari, фізичні пристрої, 200% zoom та реальне офлайн-перезавантаження не
перевірялися. Чинність нормативної редакції повторно не звірялася.
Push, merge або deployment не виконано.

## Архів і Vercel

Файли лежать у корені ZIP. Спершу розпакуйте архів та оновіть вихідні файли
проєкту своїм звичним способом; цей ZIP не є готовим deployment-артефактом.

Поточний `vercel.json` уже містить `framework: nextjs` і
`buildCommand: npm run build:next`. Корінь проєкту — каталог із `package.json`.
Залежності: `npm ci`. Репозиторій вимагає Node.js ≥22.13.0; перевірено на
Node.js 24.19.0. Локальна перевірка: `npm run build:next` → `npm run start:next`.
Не підміняйте Vercel build командою `npm run build`: вона призначена для
іншого наявного production-шляху vinext/Cloudflare.

Після власного деплою перевірте пошук → пункт → параметри → пояснення,
порівняння й ТДВ у двох темах на телефоні та настільному екрані.
