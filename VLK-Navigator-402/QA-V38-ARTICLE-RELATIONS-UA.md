# VLK v38 — повні перехресні посилання між статтями

## Що змінено

Перевірено 87 статей Розкладу, їхні дослівні «Включено / Виключено»,
пункти й 87 записів пояснень корпусу редакції 22.08.2025.
Порожній запис пояснення до статті 87 також врахований.

Виявлено 47 унікальних спрямованих цифрових зв’язків у 31 статті:
37 із пояснень і 10 із «Виключено». Це 56 окремих згадок у тексті.
До старої карти додано 13 зв’язків: 11 → 8/9/10 та 10 посилань із Розкладу.
Раніше навіть уже записані посилання губилися після п’яти статей тієї самої групи.

Тепер у «Схожі / суміжні статті»:

1. Усі прямі посилання стоять першими; ліміт скорочує лише групову добірку.
2. Для кожного переходу доступні дослівні підстави та джерело редакції №402.
3. Перенаправлення з «Виключено» підписані окремо; це не твердження про взаємозамінність діагнозів.
4. Для ненумерованих відсилань доступна навігація за органом / системою або групою хвороб.
5. Групова схожість відокремлена від прямого нормативного посилання.

Прямі зв’язки спрямовані: зворотне посилання автоматично не створюється.
Якщо в різних абзацах згадано ту саму статтю, картка одна, а всі підстави збережені.

## Туберкульоз та ненумеровані переходи

Знайдено 31 фрагмент у 30 статтях: 26 із ненумерованою відсилкою до інших
статей і ще 5 із перенаправленням до основного захворювання (12, 22, 23, 38, 39).
Для статті 2 показується повна умова про одужання після проведеного курсу
лікування, анатомічну зону ураження та порушення функцій.

Вибір «Хвороби органів дихання» відкриває навігаційний список 45–48;
вибір «Хвороби кістково-м’язової системи» — 60–65. Це перелік статей групи
для читання, а не автоматичне зіставлення туберкульозу з конкретною статтею.
Лікар сам перевіряє відповідність стану, застосовність норми та пункт.
Інші групи також доступні; числові посилання від імені наказу не вигадані.

Дослівні цитати 51 → 56 і 60 → 61 доповнені попередніми абзацами,
щоб «указаними захворюваннями» та «цього пункту» зберігали контекст.
Умови контракту, граф, лікування й винятків не відкидаються.

## Збережені частини

101 захищений файл побайтно збігається з v37: нормативні тексти,
усі пояснення, пункти/результати, МКХ, ТДВ, якорі, пошук,
категорії/графи та формат локальної сесії. Перевірку зафіксовано окремо.

Навігація використовує наявний обробник відкриття статті. Категорія,
графа та призначення ТДВ зберігаються; пункт не обирається автоматично.
Після переходу фокус повертається на заголовок, область читання починається
зверху. Нових сховищ, мережевих запитів, залежностей або анімацій немає.
Пояснення надалі завантажуються постатейно; індекс містить посилання на абзаци,
а не копію всіх текстів у початковому бандлі.

## Розгортання

ZIP містить файли у корені, lockfile, локальні шрифти, ресурси й PWA.
Node.js >=22.13.0. Для Vercel: Next.js, Root Directory — каталог із
`package.json`, Install Command — `npm ci`, Build Command — `npm run build:next`.
Локальний production-запуск: `npm run start:next`.
`npm run build` залишається окремим vinext/Cloudflare шляхом.

Без node_modules, .next, dist, кешів, логів, приватних .env та вкладених ZIP.
Деплой у production не виконано. Фізичні iOS/Safari та незалежне клініко-правове
приймання не проводилися.
