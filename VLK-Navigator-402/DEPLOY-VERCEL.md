# v19 — збірка і тестовий деплой на Vercel

У ZIP уже інтегровано поєднане оформлення: темно-зелена командна оболонка,
світла площина для читання норм, латунні акценти, військово-медична емблема
та делікатна анімація. Застосунок має один режим — робоче місце лікаря ВЛК.

## Найкоротший шлях

1. Розпакуйте ZIP. `package.json` і `vercel.json` розташовані безпосередньо
   в його корені. Завантажте розпаковані файли до свого Git-репозиторію;
   сам ZIP не є вихідним кодом для збірки.
2. Імпортуйте цей репозиторій у Vercel. **Root Directory** — папка з
   `package.json`: корінь репозиторію або підпапка, куди ви поклали файли.
3. **Framework Preset:** Next.js. **Build Command:** `npm run build:next`
   (у `vercel.json` уже записано цю команду; вона також створює офлайн-маніфест). Не використовуйте
   `npm run build` для Vercel: це окремий шлях Cloudflare/vinext.
4. **Install Command:** `npm ci`. Залиште типовий Output Directory для Next.js.
   Використайте Node.js 22.x, не нижче 22.13.0. Додаткові змінні середовища
   для поточного навігатора не потрібні. Встановлення залежностей і завантаження
   шрифту під час чистої збірки потребують мережі.
5. Спочатку перевірте Preview deployment із тестової гілки. Реальний деплой
   у вашому Vercel-акаунті в межах цієї роботи не виконувався.

Якщо Vercel повідомляє, що `package.json` не знайдено, виправте Root Directory.
Якщо збірка намагається запускати vinext, установіть Build Command вище.

## Перед публічним запуском

- На комп'ютері та телефоні перевірте пошук статті й МКХ, спеціальності,
  вибір пункту, копіювання формулювання та повернення до збереженої локальної сесії.
  паспорт норми, довгі пояснення, ТДВ та офіційні посилання.
- Перевірте клавіатуру, фокус, читабельність, відсутність горизонтального
  прокручування та вимкнення анімації за системним Reduce motion.
- Після першого завантаження перевірте офлайн-поведінку, відкриття вже
  завантажених пояснень і оновлення з попереднього service worker.

Фактично виконані перевірки й межі наведені в `QA-V19.md`. Фізичні пристрої, Windows-масштабування та production-оновлення кешу перевіряйте за `review/RELEASE-REVIEW.md`.

## Нормативні обмеження

Збережено корпус попередньої версії з датою редакції **22.08.2025**. Цей
дизайн-реліз не підтверджує чинність корпусу на день використання й не
замінює постанову ВЛК. Автоматичні тести перевіряють інваріанти даних, а не
законність рішення щодо конкретної людини. Іменні перевірки лікаря ВЛК та
військово-медичного юриста залишаються незавершеними.

Workflow `.github/workflows/vlk-edition-monitor.yml` налаштовано на щоденну
перевірку джерела. Для запуску файл має бути в основній гілці GitHub, Actions
мають бути дозволені, а джерело — доступне. Vercel не запускає цей workflow.
Якщо застосунок лежить у підпапці репозиторію, перенесіть workflow до кореневої
`.github/workflows/` і задайте цю підпапку як робочу директорію його команд.
Сповіщення та успішний запуск моніторингу у вашому репозиторії потрібно
перевірити окремо. Автоматичної заміни нормативних текстів немає.
