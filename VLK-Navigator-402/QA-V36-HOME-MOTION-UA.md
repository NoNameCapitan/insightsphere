# v36 — головна без дублювання, жива змія банера

Дата роботи: 29.09.2026. Основа — точний випуск v35 compact-workspace.

## Реалізовано

- Картки лікарів залишено основним вибором спеціальності.
- У порожньому швидкому доступі немає дубльованої кнопки переходу за
  спеціальністю. Замість неї — коротка підказка про перегляд/закріплення статей.
- Пошук має коротку підказку «Діагноз, МКХ-10 або № статті…».
  Повна доступна назва збережена; пошукова семантика та словники незмінні.
- «Область пошуку» звужує результати у робочому екрані.
- Вкладка коротких стартових списків перейменована на «Добірки статей».
  Це відокремлює добірки від переходу в повний розділ лікаря; самі добірки збережено.
- Банер: фактична висота desktop 158 px (у v35 — 122 px); трохи більші заголовок
  та емблема. Порожня головна 1440×900 усе ще вміщується без прокручування.
- На телефоні 390×844: висота головної 1179 px, природне вертикальне прокручування;
  горизонтального прокручування сторінки немає.
- Зірка верхньої лівої емблеми замінена стилізованою гілочкою калини.

## Анімація

Векторна змія банера використовує ту саму траєкторію, що й логотип.
Голова й тіло обчислюються з одного шляху; шари перед/за чашею збережено.
Відстань уздовж траєкторії вирівняна для спокійнішої швидкості, початок
і завершення плавно сповільнюються. Тривалість — 5,2 с.

Один цикл за сеанс вкладки. Повернення зі статті, повторний hover та reload
не повторюють його. Прапорець `vlk-402-hero-intro-v1` зберігається у sessionStorage,
не містить медичних чи персональних даних. Якщо сховище недоступне,
працює fallback у пам'яті на час відкритої сторінки (reload у такому режимі
може запустити вступ знову). Нова вкладка починає окремий сеанс.

Reduced motion одразу показує завершену статичну позу. При приховуванні вкладки
активний цикл завершується. Немає нескінченних інтервалів чи циклу кадрів у спокої.
Hover логотипа не створює паралельної анімації під час вступу банера;
клік на логотипі з робочого екрана одразу повертає на головну.
Чаша й рамка нерухомі; анімація не змінює габарити банера.

Побайтово порівняно з v35: `lib/`, `public/`, усі попередні тести, lockfile,
package.json та конфігурації не змінені. Нормативні тексти, результати,
МКХ, ТДВ, локальний лікарський стан і пошукові алгоритми не редагувалися.
Дати корпусу 22.08.2025 і перевірки джерела 09.09.2026 збережено.

BLOCKED / не перевірено: production Vercel, фізичні iOS/Safari, системний друк,
реальне оновлення service worker з попередньої версії. Наявні PWA-тести
та створення офлайн-маніфесту проходять; це не перевірка офлайн на пристрої.
Нової перевірки чинності нормативного джерела не проводили.

ZIP містить lockfile, ресурси та інструкцію запуску. Без node_modules,
.next, dist, кешів, логів, локальних .env і секретів. Для Vercel:
`npm ci` → `npm run build:next`; локально `npm run start:next`.
