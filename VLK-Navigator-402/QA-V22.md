# Перевірка v22

Основа: v21, зібрана з наданого користувачем `VLK-Navigator-402-v19-release(4).zip`.
Продакшен не змінювався. Результат — вихідний ZIP для тестового деплою.

## Графи I / II / III

- Вибір графи зроблено окремо від категорії оглядуваного: застосунок не
  припускає автоматичної відповідності між цими полями.
- Обрана графа зберігається в локальній сесії. Старі сесії без цього поля
  відкриваються як «Усі графи».
- У центральній панелі доступний згорнутий блок із дослівними абзацами, де
  обрану графу названо прямо. За відсутності такого абзацу дані не вигадуються.
- Розпізнаються `I–III`, `II–III`, переліки `II, III`, дефіси різних типів і
  українська літера `І`. Римські цифри без слів «графа/графою/графами/графи»
  не вважаються графами.
- У захищеному корпусі знайдено 20 прямих абзаців для графи I, 25 для II та
  26 для III. Це лічильники згадок, а не кількість нормативних рішень.

## Копіювання

- Кнопка «Скопіювати формулювання пункту» розташована серед основних дій
  розгорнутої картки.
- Текст містить статтю й пункт, дослівний стан, дослівний результат, обрану
  графу, редакцію, посилання на джерело та застереження.
- Повне копіювання з поясненнями додатково включає тільки передані дослівні
  абзаци для обраної графи.
