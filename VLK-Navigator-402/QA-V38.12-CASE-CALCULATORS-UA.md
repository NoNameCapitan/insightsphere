## «Випадок»

- Одне широке поле приймає кілька кодів: `39б, 40в, 13в, 28б`
- Коректне ціле введення одразу враховується у попередньому результаті;
  Enter / «Додати» закріплює позиції; помилковий перелік не враховується частково
- Зріст і вага лишаються поруч; немає потреби заповнювати все, щоб побачити
  вже встановлену позначку або відсутню підставу
- Порожній випадок показує одну коротку підказку замість 12 порожніх карток
- Результат складається з компактних груп: «Не проходить введені критерії»,
  «Потрібне уточнення», «Дозвіл не встановлено», «Перевірені критерії виконано»
- У кожному рядку — зрозуміла назва призначення, коротка підстава та «Чому»;
  номер графи допоміжний
- Роль водія / члена екіпажу та чинник КРП з’являються без прихованого меню,
  тільки коли у введених пунктах є відповідна умовна позначка
- «Чому» відкриває всі окремі підстави: дослівну позначку, числову межу,
  незаповнену клітинку / відсутній рядок, повну назву графи та джерела
- Відсутні рядки, порожні клітинки й невідомі умови не стають зеленим дозволом;
  числовий результат позначає лише перевірені числові межі
- Для водолазних посад є окреме застереження про неперевірені додаткові умови

Це зіставлення введених критеріїв з окремими нормами ТДВ. Загального
висновку про придатність або автоматичної постанови ВЛК немає.

## Калькулятори терапевта

Над робочою областю терапевта доступні три компактні кнопки. Введені
значення тимчасові; оновлення сторінки, завершення сесії, міжвкладкове
очищення або вихід із розділу терапевта їх прибирає. Закриття й повторне
відкриття калькулятора у тому самому розділі зберігає введення.

### ІМТ

ІМТ = вага (кг) / [зріст (м)]². У коді використана алгебраїчно еквівалентна
форма вага × 10000 / зріст(см)², щоб уникнути похибки на точних порогах
типу 160 см / 76,8 кг = 30.

Категорії для дорослих: <18,5; 18,5–<25; 25–<30; 30–<35; 35–<40; ≥40.
Це довідкові категорії, не діагноз.

### ММЛШ

Лінійна формула ASE:

`0,8 × 1,04 × [(МШПд + КДР ЛШ + ЗСЛШд)³ − КДР ЛШ³] + 0,6 г`

Всі три поля — кінцево-діастолічні розміри у **мм**. Перед піднесенням
до куба значення один раз переводяться в **см**. Альтернатива — ввести
вже виміряну масу з протоколу ЕхоКГ у грамах.

### ІММЛШ

- ППТ (Mosteller) = √[зріст (см) × вага (кг) / 3600]
- ІММЛШ = ММЛШ (г) / ППТ (м²)
- Розрахунок виконується без статі; стать потрібна тільки для показу
  референтних меж
- Лінійний метод: жінки 43–95, чоловіки 49–115 г/м²
- Двовимірний об’ємний метод: жінки 44–88, чоловіки 50–102 г/м²
- Розміри, взяті з 2D-зображення, самі по собі не означають 2D-об’ємний метод
- Для готової маси невідомого методу немає референтної класифікації
- Верхня межа перевищена лише при строгому `>`; рівність не є перевищенням
- При ІМТ ≥30 видиме застереження: індексація на ППТ може приховувати
  збільшення маси ЛШ; лікар має інтерпретувати результат у контексті

Немає проміжного округлення; округлюється лише відображення. Від’ємні,
нульові, нескінченні, неоднозначні значення й порожні поля не перетворюються
на результат. Кома і крапка підтримуються. Довільних клінічних мінімумів
або максимумів не встановлено. Зміна поля на некоректне одразу прибирає
попередній результат.

- [Mosteller 1987, бібліографічне джерело](https://pubmed.ncbi.nlm.nih.gov/3657876/)
- [ASE/EACVI: індексація при ожирінні](https://www.asecho.org/wp-content/uploads/2015/07/2015_Hypertension.pdf)
- [ВООЗ: ІМТ у дорослих](https://www.who.int/data/gho/data/themes/topics/topic-details/GHO/body-mass-index)
- [CDC: категорії та ступені ІМТ](https://www.cdc.gov/bmi/adult-calculator/bmi-categories.html)

Mosteller — явно обраний спосіб обчислення ППТ, без твердження, що він є
єдиним обов’язковим методом. Числа з калькуляторів не передаються до
механізму оцінки «Випадку».

## Контрольні приклади

| Зріст / вага | МШПд / КДР / ЗСЛШд, мм | ММЛШ, г | ІММЛШ, г/м² |
|---|---|---:|---:|
| 175 см / 70 кг | 10 / 50 / 10 | 181,976 | 98,6500524835 |
| 180 см / 80 кг | 12 / 54 / 11 | 249,425408 | 124,712704 |
| 160 см / 60 кг | 9 / 45 / 9 | 132,823104 | 81,3372077132 |

Для 180 см / 80 кг ППТ = 2 м²: 190 г → 95 г/м², 230 г → 115 г/м².
Обидві рівності входять у відповідний лінійний референтний діапазон.

## Запуск

Файли проєкту лежать у корені ZIP. Node.js ≥22.13.0.

```bash
npm ci
npm run build:next
npm run start:next
```

Перед використанням у роботі перевірте у своєму браузері групи «Випадку»
на телефоні й комп’ютері та наведені числові приклади калькуляторів.
