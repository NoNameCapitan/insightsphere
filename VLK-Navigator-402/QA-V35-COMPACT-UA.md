# v35 — звіт перевірки компактного інтерфейсу

Дата роботи: 29.09.2026. Основа: точний архів v34 quick-access.
Це UI-випуск; він не підтверджує актуальність нормативного корпусу на поточну дату.

## Реалізовано

- Компактні банер і проміжки на головній; картки спеціальностей збережено.
- Порожній швидкий доступ: текст та одна дія, 65 px на desktop.
- Заповнений: шість позицій; закріплені першими; повний список до десяти
  і добірки за спеціальністю — у наявному діалозі.
- Очищення статистики — у розділі налаштувань; закріплення зберігаються.
- Останні перегляди, офіційне пояснення та суміжні статті початково згорнуті.
- Копіювання всього офіційного пояснення доступне і в згорнутому стані;
  повноекранний документ, фрагменти, таблиці та джерело збережено.
- Суміжних статей максимум п'ять, лише з наявних зв'язків.
- ТДВ: компактний рядок, без зміни сфери застосування чи позначок.
- Короткі видимі підписи дій на вузьких екранах із повними доступними назвами.
- Усунено виявлений під час QA конфлікт React-ключів сусідніх блоків,
  який спричиняв дублювання пояснення після повторного пошуку.

## Змінені компоненти

`app/page.tsx`, `app/globals.css`, `components/vlk/quick-access.tsx`,

## Вимірювання

| Сценарій | v34 | v35 |
|---|---:|---:|
| Порожня головна 1440×900: висота документа | 1215 px | 900 px |
| Порожній швидкий доступ desktop | близько 306 px | 65 px |
| Читання 390×844, стаття 49 | 363 px | 403 px |
| Читання 768×1024, стаття 49 | 583 px | 625 px |

Заповнена головна 1440×900: 970 px (70 px прокручування).
На 1920×1080 порожня й заповнена головна вміщуються.
На 1366×768 порожня головна має 806 px; на телефоні природне вертикальне
прокручування збережено. Горизонтального overflow сторінки в перевірених станах немає.

## Команди

- PASS — `npm ci` (685 пакетів, чисте встановлення).
- PASS — `npm run lint`.
- PASS — `npx tsc --noEmit`.
- PASS — `WRANGLER_SEND_METRICS=false npm test`: 159/159, без пропущених;
  команда також виконує vinext/Cloudflare build.
- PASS — `npm run build:next`: production Next.js і офлайн-маніфест (144 ресурси).

Перевірки виконано на Node 24.19. Початкова спроба використати symlink
node_modules була відхилена Next.js; замінена чистим npm ci. Для vinext
використано наявний кеш завантажених шрифтів; кеш не включено до ZIP.
Проміжний source-test виправлено поверненням значущого доступного підпису,
без зміни тесту. Фінальних FAIL немає.

Chromium, production Next.js: 1440×900, 1366×768, 768×1024, 390×844;
світла/темна теми; окремо головна 1920×1080. Реальні кліки й клавіатура.

- PASS — стоматолог → стаття 49 → пункт в → пояснення → ТДВ → повернення.
- PASS — пошук скорочення, клінічної фрази, МКХ й номера; /, Esc, стрілки/Enter;
  фільтри, історія 15 запитів, очищення та відновлення після reload.
- PASS — порівняння пунктів, вибір графи, збереження контексту й повернення фокуса.
- PASS — швидкий доступ, закріплення, очищення статистики без втрати закріплень,
  добірки за спеціальністю, суміжні статті, завершення сесії.
- PASS — фактичний буфер обміну дорівнює повному поясненню статті 13,
  включно з таблицями; при відмові Clipboard API доступне ручне копіювання.
- PASS — ТДВ статті 47: відсутність запису для а, точні позначки для в;
  для 49 збережено загальну сферу вимог, без вигаданої прив'язки до пункту.
- PASS — початково згорнуті блоки, клавіатурне розкриття, копіювання без розкриття,
  шість preview/десять у діалозі, закріплені першими, відсутність дублікатів DOM.
- PASS — reduced motion, діалоги, відсутність JavaScript pageerror.

## Незмінне та межі перевірки

Побайтово збережено lib/, нормативні тексти, public/, тести, package.json,
lockfile та конфігурації. Ключі/формати localStorage й пошукова семантика незмінні.
Не змінено дати редакції 22.08.2025 та перевірки джерела 09.09.2026.
Анімації спеціальностей та емблеми залишено без нового motion-дизайну.

BLOCKED / не перевірено в цьому середовищі: production Vercel, фізичні iOS/Safari,
системний друк, реальне офлайн-оновлення service worker з попередньої версії.
Генерація офлайн-маніфесту і наявні автоматизовані PWA-тести проходять;
це не замінює перевірку офлайн на пристрої. Нової юридичної/клінічної
верифікації корпусу не проводили. Повного аудиту WCAG не заявляємо.

Для Vercel використовуйте `npm run build:next`, не `npm run build`.
Архів не містить node_modules, .next, dist, кешів, локальних .env чи секретів.
