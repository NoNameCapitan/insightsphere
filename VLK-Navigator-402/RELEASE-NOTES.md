# v14 — командно-медичне оформлення

Контрольний пакет для тестового деплою, 08.09.2026.

## Змінено

- Поєднано темно-смарагдову командну оболонку зі світлими робочими панелями
  та латунними акцентами. Додано емблему, фонову текстуру й водяні знаки.
- Оформлено шапку, навігацію, вибраний пункт, підготовку громадянина та
  паспорт норми. Ролі «Лікар» і «Громадянин» та логіку роботи збережено.
- Додано повільну фонову анімацію та підсвічування пункту з явним вимкненням
  для `prefers-reduced-motion`. Усунуто CSS-конфлікт позиціювання шапки.
- Оновлено іконки застосунку та список ресурсів service worker; версію кешу
  підвищено до v4. Уточнено умови запуску моніторингу й інструкції деплою.
- Додано чотири регресійні тести структури оформлення. Вони не перевіряють
  реальний вигляд у браузері.

## Фактичні перевірки фінального коду

Середовище: Node.js 24.19.0, npm 11.9.0, наявні встановлені залежності.

| Перевірка | Статус | Результат |
| --- | --- | --- |
| `npm run lint` | PASS | Без помилок |
| `npm run build:next` | PASS | Next.js 16.2.6, TypeScript, статичні сторінки |
| `npm run build` | PASS | vinext/Cloudflare build завершено |
| `node --test tests/*.test.mjs` | PASS | 63 тести, 0 помилок, 0 пропусків |
| Порівняння з v13 | PASS | Усі 109 файлів `lib/`, `package.json`, lockfile і `vercel.json` незмінні побайтово |
| Чисте перевстановлення `npm ci` | BLOCKED | Спробу в ізольованій папці зупинено на запиті дозволу середовища; повторного встановлення не виконано |
| Браузерний та візуальний аудит | BLOCKED | Браузер недоступний; див. `design-qa.md` |
| Деплой у Vercel-акаунті користувача | Не виконувався | Надано вихідний ZIP та інструкцію |
| Живе джерело, запуск моніторингу та іменні експертні перевірки | Не виконувалися в v14 | Чинність редакції на сьогодні не підтверджено |

Збірка vinext попереджає про клієнтський chunk понад 500 kB та неповну
статичну класифікацію маршруту. Це не помилки збірки, але фактичну швидкість
завантаження потрібно оцінити на Preview, особливо з мобільного інтернету.

## Межа відповідальності цього випуску

Нормативний корпус залишено з редакцією **22.08.2025**. Макети й нове
оформлення не є юридичним джерелом. Автоматичні інваріанти та тести не
становлять експертного підтвердження й не гарантують нормативної точності.
Окремий модуль перевірки процедури не додано. Авторизацію, аналітику й
передавання медичних даних не додано.

Наступна дія: тестовий Vercel Preview за `DEPLOY-VERCEL.md`, потім
браузерна перевірка та незалежна перевірка нормативного змісту до реального
застосування лікарями або громадянами.
