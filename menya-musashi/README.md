# Menya Musashi Kyiv — Network edition

Неофіційна дизайн-пропозиція Івана Жаркова, листопад 2026. Одна кодова база — персональний сайт кожної з дев’яти київських філій. Статичний HTML/CSS/JS без збірки й бекенду; оплата та замовлення лишаються в Choice.

## Що відкривати
| Файл | Для кого | Що це |
|---|---|---|
| `index.html` | гості | Сайт філії. `?venue=torisho` (або `/torisho` на хостингу) відкриває конкретну філію |
| `network.html` | команда, інтегратор | **Network Studio**: живий конфігуратор, усі філії з QR, схема інтеграції, віджет, план запуску |
| `proposal.html` | керівник | Комерційна пропозиція для мережі |
| `Menya-Musashi-Network-Proposal.pdf` | пошта / месенджер | Та сама пропозиція у PDF (10 сторінок) |
| `docs/INTEGRATION.md` | розробник | Як додати філію, контракт даних, синхронізація, деплой |
| `docs/SALES-KIT.md` | тільки ви | Скрипт презентації, листи, заперечення |

## Швидкий старт
- Локально: двічі клікнути `index.html` (працює з диска) або `python3 -m http.server` у цій папці й відкрити `http://localhost:8000`.
- Хостинг: залити папку на Netlify або Vercel як є. `_redirects` / `vercel.json` дають адреси `/podil`, `/lypky`, `/torisho`, `/holosiiv`, `/bazhana`, `/obolon`, `/lavina`, `/vynohradar`, `/beresteiskyi` і заголовок `noindex`.

## Персоналізація посиланням
`index.html?venue=torisho&accent=e64a2e&dish=Бао&headline=Вечір|у Torisho.` — філія, акцентний колір, фірмова страва на першому екрані, заголовок (`|` розділяє рядки). Такі посилання генерує Network Studio разом із QR і JSON-конфігом.

## Анімації
Прелоадер-печатка (раз за сесію, клік пропускає) · поява заголовка й торіїв · жива пара на canvas · паралакс від курсора й прокрутки · кухар, керований прокруткою (8 кадрів) · горизонтальна галерея з піннінгом · мапа з пульсуючими точками · магнітні кнопки та курсор на десктопі · налив лимонаду. Перемикач «Рух» і системне «зменшити рух» вимикають усе: контент лишається доступним.

## Структура
`css/base.css` — дизайн-система; `css/v3.css` — сайт філії; `css/studio.css`, `css/proposal.css`.
`js/data.js` — знімок меню 06.11.2026; `js/hires.js` — найчіткіші фото; `js/branches.js` — **конфіг філій**; `js/app.js` — меню, пошук, обране, картка страви; `js/experience.js` — анімації та персоналізація; `js/studio.js` — Network Studio; `js/embed.js` — віджет; `js/vendor/` — GSAP 3.12.5 + ScrollTrigger, qrcode-generator.

## Перед показом
1. Контакти в `proposal.html` (блок «Наступний крок», `data-fill="contacts"`), потім перегенерувати PDF.
2. Ціни пакетів (45 000 / 140 000 / 18 000 ₴/міс) — орієнтир, змініть під себе.
3. Координати філій на мапі приблизні (схема) — перевірте в `js/branches.js`.
4. Плашку «Неофіційна концепція» не прибирати до погодження з мережею.
