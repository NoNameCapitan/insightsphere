# Menya Musashi Kyiv — Premium edition

Неофіційна дизайн-пропозиція Івана Жаркова, листопад 2026. Статичний сайт: HTML/CSS/JS, без збірки, бекенду, аналітики, оплати чи надсилання замовлень. Відкрийте `index.html` або роздайте папку будь-яким статичним хостингом (Netlify, Vercel, GitHub Pages).

## Файли
| Файл | Що це |
|---|---|
| `index.html` | Живе демо сайту |
| `proposal.html` | Комерційна пропозиція для команди ресторану (веб-версія) |
| `Menya-Musashi-Proposal.pdf` | Та сама пропозиція у PDF — для пошти й месенджерів |
| `docs/SALES-KIT.md` | Внутрішнє: скрипт першої розмови, листи, заперечення. **Клієнту не надсилати** |
| `site.css` | Єдина дизайн-система (замінила три старі шари style/edition/ink) |
| `proposal.css` | Компоненти сторінки пропозиції |
| `app.js`, `edition.js`, `ink.js` | Логіка меню, обкладинки, воріт, наливання |
| `luxe.js` | Підписні страви, статистика з даних, появи при прокручуванні, стан шапки |
| `data.js` / `hires.js` | Знімок меню 06.11.2026 / мапа найчіткіших фото за точною назвою страви |

## Що змінено в premium edition
- Нова типографіка: Cormorant (дисплей), Golos (інтерфейс), Shippori Mincho (кандзі). Палітра туш / вогонь торії / слонова кістка / шампань / смарагд.
- Перший екран: виправлено накладання картки страви на кнопку меню; великий серифний заголовок, вертикальний 麺屋武蔵, печатка 門 з обертовим написом замість кнопки «Відкрити ворота», напівпрозора шапка.
- Нові блоки: бігучий рядок, «Підписні страви» (редакційна галерея з найчіткішими фото, будується з меню обраного закладу), «Шлях Musashi» з цифрами, що рахуються з даних, фінальний CTA, футер з великим словом.
- Меню, кухня, наливання, бар, заклади, картка страви — переоформлені в одній системі. Картки меню й діалог використовують фото вищої роздільності, якщо таке саме фото страви є в іншому закладі.
- Мобільна версія: плаваюча панель «Меню / Замовити», перевірено 390 і 320 px без горизонтального прокручування.
- Рух: зерно плівки, появи при прокручуванні, лічильники — усе вимикається перемикачем «Рух» і системним «зменшити рух».
- Пропозиція: обкладинка з макетами пристроїв, цифри, шість ключових моментів зі скріншотами, шлях гостя, візуальна мова, план запуску, три пакети, чекліст, CTA.

## Перед відправкою
1. У `proposal.html` заповніть контакт: рядок `data-fill="contacts"` (телефон / Telegram / email). Перегенеруйте PDF або надішліть веб-версію.
2. Ціни пакетів (45 000 / 120 000 / 15 000 ₴/міс) — орієнтир; змініть у `proposal.html`, розділ `#packages`.
3. Плашку «Неофіційна концепція» не прибирати до погодження з мережею.
