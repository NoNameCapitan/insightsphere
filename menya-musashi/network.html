02Мережа
Дев’ять філій — дев’ять облич.
Кожна картка — окремий сайт із власною адресою. Статус «відкрито» рахується наживо за київським часом.

  







  
03Інтеграція
Як дані потрапляють на кожен сайт.

  
  

    
Етап A · зараз
Статичний сайт + Choice
Сайт уже працює на знімку меню. Замовлення та оплата — у вашому Choice. Ризик для операцій — нульовий.

    
Етап B · пілот
Автосинхронізація
Регулярний експорт меню з Choice/POS перетворюється на фіди філій. Ціни, фото та стоп-лист оновлюються без ручної роботи.

    
Етап C · масштаб
Мережа й партнери
Нова філія — рядок у конфігу. Віджет для партнерів, QR у залах, сезонні меню й акції — централізовано для всієї мережі.

  

  

    
Контракт даних філії
Мінімум, який потрібен від мережі, щоб запустити нову філію. Формат простий для будь-якої POS-інтеграції.

    

  







  
04Віджет для партнерів
Меню філії — на будь-якому сайті.
Два рядки коду — і на сайті ТРЦ, готелю чи партнера з’являється картка філії з живим статусом, фірмовими стравами й кнопкою замовлення. Стилі ізольовані Shadow DOM.

    Пілот: одна філія
    Погодження дизайну, оригінали фото, домен, аналітика переходів у Choice.

  2. Тиждень 2–3

  3. Тиждень 4–5

    Решта філій через конфіг, QR-набори для залів, віджет для партнерів.

  4. Тиждень 6
    Звіт і масштаб
    Перші цифри: відкриття меню, вибір філії, переходи до замовлення. Рішення про наступні кроки.
