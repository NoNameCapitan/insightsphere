# AI Lead Hunter · 0.3.0

Робочий простір для пошуку локальних бізнесів, оцінювання можливостей і ведення контактів. Інтерфейс українською; шаблони звернень українською, російською та англійською.

## Швидкий запуск

Потрібні **Node.js 22.19+** (рекомендовано Node.js 24) і npm.

```bash
npm ci
npm run dev
```

Відкрийте http://localhost:3000. Без ключів доступна позначена демо-вибірка вигаданих бізнесів Києва. У демо вимкнені кнопки зовнішніх звернень.

Для production:

```bash
npm run build
npm start
```

## Підключення сервісів

Скопіюйте `.env.example` у `.env.local`. Не додавайте секретні ключі до Git або архівів.

| Змінна                                | Призначення                                                                                                            |
| ------------------------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| `GOOGLE_PLACES_API_KEY`               | Серверний ключ для Places API (New). Потрібні активні API, білінг і доступна квота Google Cloud.                       |
| `NEXT_PUBLIC_GOOGLE_MAPS_BROWSER_KEY` | Необов’язковий публічний ключ Maps JavaScript API. Без нього працює безкоштовна карта OpenStreetMap.                      |
| `NEXT_PUBLIC_DEMO_MODE`               | `true` примусово вмикає демо. Для реального пошуку — `false`.                                                          |
| `AI_PROVIDER`                         | `openai`, `anthropic`, `openai_compatible` (Gemini, OpenRouter, Groq, Mistral, DeepSeek, Ollama) або `none`.           |
| `AI_PROVIDER_API_KEY`                 | Секретний ключ обраного AI-провайдера.                                                                                 |
| `AI_MODEL`                            | Ідентифікатор моделі. Для `anthropic` типово `claude-opus-5`; для інших провайдерів обов’язковий.                      |
| `AI_BASE_URL`                         | Лише для `openai_compatible`: адреса Chat Completions API, напр. `https://openrouter.ai/api/v1`.                       |
| `APP_PASSWORD`                        | Необов’язковий пароль робочого простору: HTTP Basic, довільне ім’я користувача. На публічному хостингу потрібен HTTPS. |
| `NEXT_PUBLIC_DEFAULT_CITY`            | Початкове місто у формі, типово Київ.                                                                                  |
| `NEXT_PUBLIC_DEFAULT_COUNTRY`         | Назва країни у налаштуваннях. Не є повноцінною географічною конфігурацією: регіон пошуку наразі UA.                    |

Перезапустіть застосунок після зміни конфігурації; для `NEXT_PUBLIC_*` у production потрібна нова збірка. У **Налаштуваннях** вимкніть примусове демо та натисніть **Перевірити Google** і **Перевірити AI**. Кожна кнопка виконує один мінімальний API-запит. Позначка «задано» означає лише наявність параметра, а не успішне з’єднання.

AI працює лише після натискання **Покращити з AI** у картці ліда. Провайдер отримує назву бізнесу, категорію, пропозицію, вибрані сигнали та поточну чернетку. Телефони, адреси й приватні нотатки до цього запиту не додаються. Передбачені OpenAI Responses API, Anthropic Messages API та будь-який OpenAI-сумісний Chat Completions API. Без AI залишаються редаговані локальні шаблони.

## Що можна робити

- Описати запит звичайною мовою, перевірити розпізнані параметри й змінити їх вручну. Розпізнавання запиту є локальним правиловим парсером.
- Шукати за нішею, містом (24 міста України з координатами; типово — усе місто), районом Києва, довільною адресою або геолокацією; фільтрувати й сортувати результати; перемикати картки, таблицю та карту (Google Maps або OpenStreetMap).
- Бачити контакти, які бізнес сам опублікував на сайті: email, Instagram, Facebook, Telegram, WhatsApp, Viber, TikTok, YouTube, LinkedIn. Email підставляється в лист, Telegram/Instagram/Messenger відкриваються однією кнопкою.
- Відбирати ліди масово, зберігати в кампанію без повторів, експортувати CSV, приховувати результати з можливістю повернення.
- Перевіряти пояснення оцінки 0–100 і окрему повноту даних. Це евристики, а не прогноз продажу чи підтверджений аудит бізнесу.
- Переглядати короткий HTML-аналіз сайту: HTTPS, доступність, метадані, знайдені ознаки контактів, форм і запису.
- Вести 5 етапів: Нові → Перевірені → Контакт → Діалог → Результат (перетягуванням карток або списком); додавати нотатки, ручні перевірки, підсумки й дату наступного контакту.
- Позначати «Не контактувати» — кнопки звернення блокуються, зокрема при повторному відкритті бізнесу з пошуку.
- Зберігати JSON-копії та імпортувати їх з попереднім переглядом, об’єднанням або явною заміною.

## Пошук і ліміти

Google Text Search (New) використовує `pageSize` до 20 і `nextPageToken`. Бюджет одного пошуку — до 6 запитів, «Шукати ще» — до 9; запитаний ліміт лідів не гарантує таку кількість результатів. Кандидати дедуплікуються за Place ID, а за його відсутності — назвою й адресою. Філії зі спільним телефоном не зникають.

Для відомих координат радіус застосовується до результатів. Вбудовані координати мають 24 міста України та райони Києва; пошук за містом без явного радіуса охоплює все місто. Довільну адресу чи інше місто за наявності ключа Google перетворює на координати один додатковий запит Places; без ключа застосунок прямо повідомляє, що радіус не застосовано. Остаточно зачинені заклади (`CLOSED_PERMANENTLY`) у результати не потрапляють. Відстань є прямою географічною, а не маршрутом автомобілем.

Порожня відповідь або помилка Google не підміняється вигаданими лідами. Демо вмикається тільки явно, через конфігурацію або за відсутності ключа Google.

Перевіряється до 12 унікальних сайтів за пошук. Із HTML також витягуються опубліковані контакти (email, соцмережі, месенджери); посилання «поділитися» і службові адреси відкидаються. Аналіз обмежений HTML однієї сторінки, 200 КБ, таймаутами та трьома перенаправленнями; JavaScript сторінки не виконується. Відсутня ознака в HTML не доводить відсутність функції на сайті.

## Дані та розгортання

Кампанії зберігаються у localStorage **цього браузера й цього домену**. Очищення даних браузера видалить їх; робіть резервні копії. Сховище повідомляє про пошкоджені дані та нестачу місця. Це однокористувацький застосунок: серверної БД, облікових записів, командної синхронізації та CRM-конектора немає.

Дата наступного контакту є позначкою в інтерфейсі. Автоматичного нагадування чи розсилання немає. Кнопки зв’язку відкривають відповідну програму; вони не підтверджують доставлення повідомлення.

Захист API включає перевірку JSON, розміру запиту й origin, обмеження частоти на процес та необов’язковий пароль. На кількох інстансах потрібен спільний rate limiter. Аналізатор сайтів блокує приватні адреси, перевіряє DNS і закріплює перевірену IP-адресу для з’єднання; перевірка повторюється для redirect. Це не замінює незалежний аудит безпеки перед запуском публічного SaaS.

Для Google Maps Platform діють окремі умови щодо зберігання, експорту й атрибуції. Наявність кнопок CSV/JSON не надає прав на довільне збереження Google-контенту. Перед комерційним використанням узгодьте дозволений сценарій і строки зберігання: [офіційні правила Places](https://developers.google.com/maps/documentation/places/web-service/policies). Атрибуції постачальників з API передаються в інтерфейс і CSV.

## Перевірки й структура

```bash
npm test
npm run lint
npm run typecheck
npm run build
npm audit --omit=dev
```

GitHub Actions (`.github/workflows/ai-lead-hunter.yml` у корені репозиторію) повторює ці перевірки з Node.js 24. Підсумок ревізії — `REVIEW-UA.md`, виконані перевірки — `REAL_TESTING.md`, сценарії для власних API-ключів — `QA_CHECKLIST.md`.

- `app/` — сторінки та серверні API.
- `components/` — інтерфейс пошуку, кампаній, карти й налаштування.
- `lib/` — адаптери сервісів, парсер, оцінки, сховище та валідація.
- `tests/` — модульні й інтеграційні тести з підміною зовнішніх API.
- `.env.example` — шаблон конфігурації.

Стек: Next.js 15.5, React 19, TypeScript, Tailwind CSS, Zod, Undici, Leaflet, Lucide.
