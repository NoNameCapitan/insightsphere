# Запуск у Windows · 0.6.1

Попередня Windows-адаптація. Перевірено 106 технічних тестів в Linux; запуск на справжньому Windows-комп'ютері ще не перевірений. У Windows доступні ядро, браузерний інтерфейс, ручна передача ChatGPT і адаптер Ollama. Claude Code у Windows вимкнений до окремої перевірки керування процесами. Mac-запускачі залишаються в архіві.

## 1. Розпакування

Завантажте ZIP. Відкрийте Провідник (Win+E), перейдіть у Завантаження. Натисніть правою кнопкою на ZIP → Видобути все / Extract All → Видобути. Відкрийте отриману папку, потім orchestrator-pilot. Не запускайте файли з перегляду ZIP: потрібна вся розпакована папка.

## 2. Перевірка

Двічі натисніть CHECK-WINDOWS.cmd. Дочекайтеся повідомлення «Проверка завершена». У папці з'явиться windows-diagnostics.json. Надішліть цей файл у чат: перетягніть на поле повідомлення й натисніть Надіслати. Генерація моделі під час діагностики не виконується. Обсяг пам'яті Windows ця версія діагностики поки не визначає.

Якщо бачите повідомлення про відсутність Python, виконайте наступний пункт. Якщо будь-яка інша помилка — надішліть скриншот чорного вікна; не закривайте його до збереження повідомлення.

## 3. Python, якщо його немає

Потрібен Python 3.10 або новіший. Відкрийте https://www.python.org/downloads/ та встановіть офіційний Python Install Manager для Windows: відкрийте завантажений установник → Install / Інсталювати. Потім відкрийте Пуск, введіть Terminal, натисніть Enter. Введіть `py install 3.14` і натисніть Enter, дочекайтеся встановлення. Закрийте Terminal і знову відкрийте CHECK-WINDOWS.cmd. Якщо команда py не знайдена або установка заборонена організацією, надішліть повідомлення про помилку.

Офіційна інструкція: https://docs.python.org/3/using/windows.html. Python Install Manager може завантажувати середовище Python; моделі ці запускачі не встановлюють.

## 4. Запуск

Двічі натисніть START-WINDOWS.cmd. Залиште чорне вікно відкритим. Має відкритися браузер. Якщо цього не сталося, вставте в адресний рядок http://127.0.0.1:8765 і натисніть Enter. Якщо в чорному вікні помилка, ручне відкриття адреси її не усуне — надішліть скриншот.

## 5. Перша перевірка інтерфейсу

Ліворуч натисніть «Инструменты» → «Проверить подключения». Статус відсутності Ollama не заважає використанню ручного ChatGPT. Далі натисніть «Задачи» → «Открыть пробную подборку». Це обробляє збережені матеріали, а не запускає новий веб-пошук чи модель.

Інструкція ручної передачі відповідей — CHATGPT-WORKFLOW-RU.md. Для аналізу локально потрібна окремо встановлена розмовна модель Ollama; автоматичного завантаження моделі немає. Назву моделі підберемо після перевірки комп'ютера.

## 6. Завершення та повторний запуск

У чорному вікні натисніть Ctrl+C. Якщо з'явиться «Terminate batch job (Y/N)?», натисніть Y та Enter. Наступного разу знову відкрийте START-WINDOWS.cmd. Дані зберігаються в %LOCALAPPDATA%\OrchestratorPilot\state.sqlite3. Перенесення ZIP не переносить базу автоматично.

Перед оновленням зупиніть програму й збережіть копію бази. Зміна коду 0.6.1 змінює хеш експерименту: для застосування нових інструкцій потрібне нове порівняння. Старі результати залишаються в історії.

У 0.6.1 відсутність бази часових поясів не спричиняє падіння: строк потребує ручної перевірки. Реальний запуск Windows ще треба перевірити.
