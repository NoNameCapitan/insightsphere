# Работа с оркестратором в ChatGPT

Этот документ описывает процесс работы, а не устанавливает новый навык и не создаёт автоматический фоновый сервис.

1. Прочитать актуальные предпочтения из паспорта проекта или предоставленного экспорта контекста.
2. Для задачи определить конкретный итог, обязательные проверки и достаточный объём поиска.
3. Использовать уже доступные инструменты. Новую интеграцию искать только для конкретной отсутствующей возможности.
4. Для свежих возможностей найти первичные страницы и прочитать их. Не принимать сниппеты, суммы в откликах или соседние объявления за условия заказчика.
5. Зафиксировать по каждому материалу URL, дату проверки, условия, дедлайн, неизвестные параметры, оценку соответствия и следующее действие.
6. Подготовить пакет `schema_version: 1` по примеру `data/materials-template.json`. Не подставлять `source_opened: true`, если страница не была прочитана. Не добавлять API-ключи, полные тексты страниц или секреты.
7. Проверить материалы: источники и смысл — исследователем; поля, даты, дедупликацию и ограничение шагов — локальным ядром. При существенной задаче привлечь отдельного проверяющего с явным объёмом работы.
8. Создать отчёт с разделением фактов, оценок и неизвестного. Если подходящих вариантов мало, выдать меньше, а не заполнять список неподтверждёнными.
9. Сохранить результат и обновить историю. После этапа сообщить, что сделано, как реализовано, чем проверено, что осталось и какой следующий шаг.

В новом чате приложите паспорт или экспорт, если актуальный контекст не подгрузился. Сохранённый файл сам по себе не гарантирует его автоматического прочтения в каждом новом разговоре.

Повторные команды для переходов по согласованным этапам не требуются. Конкретный график фоновых запусков в этом проекте ещё не установлен. Ранее существовавшие автоматизации не изменялись.

## Передача задач между приложением и этим чатом · версия 0.3

В задаче с материалами выбрать «ChatGPT · по запросу» и нужную роль. Вариант «Аналитик → проверяющий» последовательно готовит два разных запроса.

1. Скачать `chatgpt-request.md` из карточки роли и передать файл в этот чат.
2. Получить JSON-файл с `run_id` из запроса и `result` по приложенной схеме. Не заменять идентификатор вручную.
3. Нажать «Импорт ответа» в той же карточке. Программа сопоставит цитаты и ссылки со снимком материалов.
4. Для бригады после принятия ответа аналитика автоматически появится запрос проверяющему. Повторить передачу.

Прямого доступа локальной программы к аккаунту или истории ChatGPT нет. Контекст передаётся выбранным пакетом; профиль и заметки проекта включены в него. Статус «Формат и цитаты проверены» не означает повторное открытие внешних источников.
