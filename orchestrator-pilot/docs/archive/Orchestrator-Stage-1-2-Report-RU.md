# Оркестратор — отчёт по этапам 1–2

Дата: 25.09.2026 · Сборка: 0.2.0

## Что выбрано

Направления: исследования и проверка фактов, автоматизация повторяющихся задач, поиск возможностей заработка. Приоритеты: точность, низкая стоимость, сохранение контекста. Интерфейсы: ChatGPT, Mac, браузер.

## Статус пяти этапов

| Этап | Статус | Результат |
|---|---|---|
| 1. Определение успеха | Завершён | Зафиксированы профиль, первый сценарий, входы/выходы, критерии и способ измерения |
| 2. Ядро | Прототип реализован и проверен через HTTP | SQLite, планы, материалы, журнал, контрольные точки и отчёты; визуальная проверка ещё не выполнена |
| 3. Подключение возможностей | Начат | Каталог с фактическими статусами; предстоит выбрать автономного исполнителя для Mac |
| 4. Проверяющая бригада | Частично подготовлен | Правила проверки встроены; независимый агент проверил код; постоянная содержательная проверка результатов ещё не подключена |
| 5. Самоулучшение | Не реализован | Предстоят сравнение версий на независимых задачах, применение и откат |

## Что реализовано

Локальное приложение Python 3.10+ без сторонних Python-библиотек. В браузере доступны создание задачи, профиль, импорт материалов, продолжение обработки, результаты, журнал и экспорт. Исследование источников в этой итерации выполнено инструментами ChatGPT; локальное ядро работает с сохранёнными данными и не выдаёт это за живой поиск.

Сохраняется снимок предпочтений для каждой задачи. Повторный импорт объединяет материалы; исходные ссылки и предыдущие пакеты остаются в истории. Перед отчётом повторно проверяются даты и сроки. Контрольные точки не приводят к повторному созданию отчёта при одновременном продолжении.

## Чем проверено

- 17 автоматических технических проверок прошли.
- Через реальный локальный HTTP-сервер выполнены создание задачи, импорт, промежуточный шаг, продолжение, получение отчёта и экспорт контекста.
- Новый экземпляр хранилища прочитал ранее сохранённую контрольную точку.
- JavaScript прошёл синтаксическую проверку.
- Отдельный проверяющий воспроизвёл три ошибки: повреждение hash-ссылок, потерю прежнего импорта, устаревание оценки при возобновлении. Все три исправлены и покрыты регрессионными проверками.

## Первый практический запуск

Прочитаны пять первичных объявлений Freelancehunt. Итог обработки: **1 кандидат, 3 требуют уточнений, 1 исключён по требованиям к опыту**. Это узкий пилот по одному источнику, не полный поиск рынка.

Кандидат — небольшие ERP-доработки с Claude Code. Заказчик указывает ориентир $5–10 за небольшую задачу и стартовый месячный бюджет до $100–200. Это невысокая оплата: перед откликом имеет смысл согласовать одну ограниченную задачу. Источник: https://freelancehunt.com/ua/project/pomichnik-dlya-doopratsyuvannya-erp-sistemi/1653792.html

Остальные первичные источники и объяснения находятся в reports/pilot-research-report.md внутри архива. Условия могут измениться; проверку следует повторить перед откликом. Доступность отклика для аккаунта пользователя и надёжность заказчиков не проверены.

## Ограничения

- Визуальная проверка браузера не выполнена: облачный браузер блокирует локальный адрес, локальный Chromium не удалось установить. Запуск в Safari и на физическом Mac не проверен.
- Локальная программа не подключена к ChatGPT/API, не ищет в интернете самостоятельно, не устанавливает плагины, не запускается круглосуточно и не улучшает свой код автоматически.
- Роли локального журнала — шаги программы, а не несколько работающих моделей.
- Новых платных API-вызовов локальная программа не делает; стоимость текущей сессии ChatGPT не измерена.
- Технические проверки не равны выполнению десяти пользовательских задач. Рубеж 8/10, экономия времени 30% и преимущество нескольких агентов над одним ещё не измерены.

## Что дальше

Продолжаем этап 3: выбираем способ автономного исполнения на Mac и подключаем минимально необходимый источник. Для локальной модели нужно знать чип и память Mac; для внешнего API — провайдера и допустимый бюджет. Новая команда «продолжай» не требуется: нужны только решения, влияющие на реализацию.
