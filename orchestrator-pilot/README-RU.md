# Оркестратор · отбор заказов · 0.6.1

Локальный помощник для владельца-фрилансера: проверяет предоставленные объявления, сохраняет основания выбора и помогает решить, на что откликнуться. Поиск источников и отправка откликов пока ручные.

**Новые функции заморожены до десяти реальных задач и сравнения с обычным ChatGPT.** Отчёты из таблиц и автономная компания остаются отдельными гипотезами. Клиентские формы прежних выпусков сохранены, но не выполняют заказы.

## Запуск

Нужен Python 3.10+. Распаковать весь архив. Перед обновлением остановить приложение и сохранить копию базы.

- Windows: `CHECK-WINDOWS.cmd`, затем `START-WINDOWS.cmd`.
- Mac: `CHECK-MAC.command`, затем `START-MAC.command`. Если двойной щелчок не работает: `bash START-MAC.command` из папки проекта.
- В браузере: «Инструменты» → «Проверить подключения».

База Windows: `%LOCALAPPDATA%\OrchestratorPilot\state.sqlite3`; Mac: `~/Library/Application Support/OrchestratorPilot/state.sqlite3`. Одна база — один экземпляр приложения. JSON-экспорт сохраняет контекст, но полного обратного импорта пока нет.

## Один реальный заказ

1. Создать задачу, открыть первоисточник и импортировать материалы по JSON-шаблону.
2. Выбрать аналитика и исполнителя. Для Ollama указать подходящую установленную модель. Claude CLI доступен только на Mac/Linux после проверки совместимости; Windows-адаптер Claude отключён.
3. В режиме ChatGPT нажать «Скопировать запрос», вставить его в чат и вернуть полный JSON через поле «Вставить ответ». Скачивание и импорт файлов остаются запасным способом.
4. Проверить вывод и записать затраченное время. Совпадение цитаты с материалом не доказывает правильность вывода.

Кнопка исторического примера показывает отчёт на 25.09.2026 и не создаёт актуальную подборку. Реальные объявления проверяются по текущему времени. Если база часовых поясов недоступна, дедлайн требует ручной проверки; приложение не должно падать.

## Исполнение и расходы

Один реальный вызов одновременно, до четырёх попыток на задачу, до 120 секунд на вызов. Автоматического платного запасного пути и повтора после перезапуска нет. Материалы передаются выбранному исполнителю. Ollama работает локально; Claude использует настройки и лимиты аккаунта, фактические дополнительные списания приложению неизвестны. Неизвестное не считается нулём. Пароли и токены приложение не копирует.

Личное использование официального Claude Code не означает разрешения обслуживать клиентов через чужие подписочные данные. Перед клиентским сервисом способ интеграции проверяется отдельно.
