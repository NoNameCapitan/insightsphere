# Изменения

## 0.6.1 · 28.09.2026 — исправления после внешнего разбора

- Приоритет: один личный сценарий отбора заказов; новые функции заморожены до реального пилота.
- SQLite-соединения закрываются после commit/rollback и исключений.
- Europe/Kyiv; отсутствие базы часовых поясов не вызывает падение, дедлайн требует ручной проверки.
- Комментарии, номер выпуска и отдельный модуль клиентского учёта не меняют хеш эксперимента. Изменения исполняемой логики выбранных модулей продолжают менять его. Старый формат хеша требует однократной перерегистрации сравнения.
- Один JSON-блок Claude с окружающим текстом допускается; несколько блоков отклоняются.
- Копирование запроса и вставка JSON в существующую карточку; прежняя проверка ответа сохраняется.
- Демо отделено от живых задач и явно показывает историческую дату.
- README сокращён; все замечания PDF учтены в отдельной матрице; есть протокол и пустая таблица десяти реальных задач.
- 106 технических тестов успешно. Реальных генераций и измеренного выигрыша нет.
