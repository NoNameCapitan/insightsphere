# Music DNA Copilot — как начать / how to start

*(English below.)*

Программа смотрит, какую музыку ты слушаешь, и подбирает треки под настроение.
Работает на твоём компьютере: без регистрации, данные никуда не отправляются.

## 1. Запусти

**Windows (проще всего):**
1. Открой https://github.com/NoNameCapitan/insightsphere/releases/latest
2. Скачай файл, в названии которого есть `windows`, и распакуй его.
3. Открой `Music DNA Copilot.exe`.
   Если появится синее окно Windows: «Подробнее» → «Выполнить в любом случае».

**macOS:** скачай файл с `macos`, распакуй, правый клик по программе → «Открыть».

**Из этого архива (нужен Python 3.10+):** дважды кликни `RUN_APP_WINDOWS.bat`
(macOS: `RUN_APP_MAC.command`, Linux: `RUN_APP_LINUX.sh`).

## 2. Пользуйся

1. Нажми **«Начать»**.
2. Выбери **«Просто попробовать на примере»**, или сразу добавь свою музыку:
   - по имени в Last.fm или ListenBrainz;
   - или файлом истории из своего сервиса. Как получить файл, написано прямо в программе.
3. Выбери настроение и нажми **«Подобрать»**.
4. Отмечай треки: **Нравится / Пропустить / Не моё**. Программа учится.

Язык меняется внизу меню: RU · UA · EN.

## In English

The app looks at what you listen to and picks tracks for your mood. It runs on your computer:
no account, nothing is uploaded.

1. **Start it.** Windows: download the `windows` file from
   https://github.com/NoNameCapitan/insightsphere/releases/latest, unzip, open
   `Music DNA Copilot.exe` (SmartScreen: More info → Run anyway). macOS: the `macos` file,
   right-click → Open. From this archive: double-click `RUN_APP_WINDOWS.bat` / `RUN_APP_MAC.command`
   / `RUN_APP_LINUX.sh` (Python 3.10+).
2. Click **Get started** and try the example, or add your music: by Last.fm / ListenBrainz user
   name, or with a history file (the app tells you where to get it).
3. Pick a mood, press **Pick music**, and rate tracks: **Like / Skip / Not for me**.
